👥 팀 협업 (4단계)

개인 모드는 그대로, "팀 컨텍스트"로 전환하면 함께 작업
단계내용핵심
Phase 1멤버십 · 초대Owner/Editor/Viewer 권한, 초대 링크
Phase 2공유 크레딧 풀팀 모드 생성비는 팀 잔액에서 차감
Phase 3a공유 캐릭터팀 얼굴/제품을 멤버 모두가 사용
Phase 3b공유 갤러리팀 생성물을 멤버 모두가 조회

🛠️ 기술 스택

Node.js · Express PostgreSQL JWT 쿠키 인증 Gemini · GPT Image Kling (비디오) Claude (캡션) Lemon Squeezy (결제) Zernio (인스타 발행) PM2 · AWS EC2

🚦 실서비스 오픈 전 체크리스트

  • Lemon Squeezy 키 6개를 .env에 입력 (결제 실동작)
  • 서버 ADMIN_PASSWORD 기본값(changeme1234) 변경
  • JWT_SECRET 운영용 랜덤 값 확인
  • 스키마 변경 배포 시 npm run migrate 실행
