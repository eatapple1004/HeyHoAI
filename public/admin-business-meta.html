Meta 직결 인스타 연동

중개(Zernio) 없이 Meta에 바로 붙는 경로입니다. 여기서 연결한 계정을 사업체에 붙이면 원본 업로드 → 콘텐츠 선택 → AI 캡션 → 예약 발행이 기존 화면 그대로 돌아가고, 발행만 Meta 직결로 나갑니다.

🚀 테스트 발행 — Graph API 직결

인스타는 파일을 받지 않고 URL로 가져갑니다. 공개 https 주소여야 하고, 상대경로(/images/…)는 자동으로 절대 URL로 바꿉니다.
영상은 인스타 인코딩이 끝날 때까지 기다리므로 수십 초 걸릴 수 있습니다 — 그동안 버튼이 잠깁니다.
