# 섹션별 작업 명령서 — 인덱스 (11개 섹션)

> Doppia 템플릿 **발굴·선별·강화**를 섹션(테마)별로 나눠 착수하기 위한 명령서 모음.
> 각 파일은 **자기완결적** — 해당 파일 하나만 보고 그 섹션 작업을 바로 시작할 수 있음.
> 공통 규칙·스키마·비용공식은 마스터 명령서 `docs/명령서_템플릿_발굴선별강화.md` 참조.

## 사용법
1. 한 섹션 = 한 세션(또는 한 작업 단위)에 그 파일 1개를 전달.
2. 각 브리프의 §8 "착수 커맨드"를 그대로 붙여넣어 시작.
3. 산출물: 섹션별 `src/recipes/seeds/recipes.<key>.v2.js` (기존은 갱신, 신규는 생성) + 한국어 산출물 스펙 + keep/cut/add 표.
4. (신규 2개) general·headshot은 완료 후 `public/studio.html`의 VERTICALS/모드에 등록해야 실제 노출됨 — 템플릿 확정 뒤 별도 와이어링.

## 병렬 처리 팁
- 9개 기존은 v2가 이미 있어 "검증·확정+산출물 스펙" 위주(가벼움). 2개 신규는 "설계"라 무겁다.
- 세션에 "ultracode"를 넣으면 멀티에이전트로 더 철저히 돈다(마스터 §8).
