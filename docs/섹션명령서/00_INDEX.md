# 섹션별 작업 명령서 — 인덱스 (12개 섹션)

> Doppia 템플릿 **발굴·선별·강화**를 섹션(테마)별로 나눠 착수하기 위한 명령서 모음.
> 각 파일은 **자기완결적** — 해당 파일 하나만 보고 그 섹션 작업을 바로 시작할 수 있음.
> 공통 규칙·스키마·비용공식은 마스터 명령서 `docs/명령서_템플릿_발굴선별강화.md` 참조.

## 운영 구조 (세션 분담)
- **워커 세션 11개**: 각자 아래 섹션 파일 1개를 맡아 `src/recipes/seeds/recipes.<key>.v2.js` 를 만든다.
- **총지휘 세션 1개**: → [00_총지휘_종합관리.md](00_총지휘_종합관리.md). `node scripts/consolidate_recipes.js` 로 전 섹션을 **수거·검증·종합**하고 [_STATUS.md](_STATUS.md)(자동생성 현황표)로 관리, 신규 2개 studio 와이어링·통합 뷰까지 마무리.
- **공유 백본 = 레포 파일시스템**(시드 파일 + _STATUS.md). 워커는 시드만 떨구면 총지휘가 수거.

## 사용법
1. 한 섹션 = 한 세션(또는 한 작업 단위)에 그 파일 1개를 전달.
2. 각 브리프의 §8 "착수 커맨드"를 그대로 붙여넣어 시작.
3. 산출물: 섹션별 `src/recipes/seeds/recipes.<key>.v2.js` (기존은 갱신, 신규는 생성) + 한국어 산출물 스펙 + keep/cut/add 표.
4. (신규 2개) general·headshot은 완료 후 `public/studio.html`의 VERTICALS/모드에 등록해야 실제 노출됨 — 템플릿 확정 뒤 별도 와이어링.
5. **로컬 검증**: 시드 수정 후 매번 파이프라인을 역설계하지 말 것 → **[_로컬검증_가이드.md](_로컬검증_가이드.md)**. 대부분 `node src/recipes/resolve.demo.js`(프롬프트) + 3스크립트 체인 + `recipeStore.list`(카드)로 끝(서버·인증 불필요). 브라우저 studio는 정말 눈으로 봐야 할 때만.

## 병렬 처리 팁
- 9개 기존은 v2가 이미 있어 "검증·확정+산출물 스펙" 위주(가벼움). 2개 신규는 "설계"라 무겁다.
- 세션에 "ultracode"를 넣으면 멀티에이전트로 더 철저히 돈다(마스터 §8).
