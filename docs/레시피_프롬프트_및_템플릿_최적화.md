# Doppia — 레시피 프롬프트 시드 + 템플릿 최적화 진단 (2026-06-08)

## 1. 산출물: 엔진용 프롬프트 시드 54개
`src/recipes/seeds/recipes.{influencer,fashion,beauty,jewelry,food,home,tech,pet,ugc}.js` (각 6개, 총 54개).
- 통합 스키마 v1(`docs/TEMPLATE_STRUCTURE.md`: A2 레이어 + A5 샷리스트)에 맞춤 → `recipeResolver.js`가 바로 소비.
- 각 레시피: `config.look.{style_preset, attributes[], extra_positive, negative}` + `shots[].{scene,pose,composition}` + 릴스는 `reel.per_shot_motion[]`. 얼굴=`identity_lock`, 제품=`product_composite`. `rationale`(존재 이유) 포함.
- ⚠️ 이 시드는 **v1 초안**. 아래 최적화 권고(병합/추가/리프라이스)를 반영해 다듬은 뒤 시드하는 걸 권장.

## 2. 최적화 진단 — "포맷은 풍부하나, 살 이유(JTBD)가 빈다"
**결론: 현재 세트는 최적이 아님.** 강점(릴스 백본 GRWM/ASMR/360/talking-pet/Empty-to-Styled = 2026 위너, 이미지 ◈2/3/4 사다리 견고)은 진짜지만, **전환에 결정적인 상업 프레임이 체계적으로 빠짐** — before/after, 사이즈/핏 온바디, 스케일/치수, 손에 든/사용 중, 정보·클레임 오버레이. 동시에 "예쁜 히어로+매크로+무드" 정물이 fashion/beauty/jewelry/food/home에서 **중복 과잉**.

### 최우선 추가 (highest leverage)
- **ugc: 정적 UGC 포토 광고 [img/◈2-3]** — 가격 바닥+커버리지를 한 번에 해결, 립싱크 리스크 0. **단일 최고 레버리지.**
- **ugc: 'TikTok made me buy it' 발견형 POV 릴스** — 2026 1순위 UGC 광고 스타일(Street Interview 슬롯과 교체).
- **fashion: 핏&사이즈 온바디 세트 + 아웃핏 전환 릴스** — 전환 최고 프레임이 통째로 없음.
- **beauty: Before/After 결과 릴스** — 뷰티 전환·광고 컴플라이언스 1순위.
- **influencer: Haul/제품 피처 릴스(제품 들고)** + Day-in-Life 릴스 — 협찬·제휴라는 실제 유료 JTBD.
- **jewelry: 스케일/사이징 샷** · **tech: in-hand 데모 릴스** · **food: 메뉴판/가격 카드 + 서빙/테이블 라이프스타일**.
- **크로스: ◈2~4 단일컷(1~2샷) 릴스 티어** — 모든 카탈로그가 가장 싼 릴스도 ◈6 바닥 → 싼 릴스 진입 + Kai 크레딧 드립 리텐션 루프 완성.

### 🔧 구조/엔진 개선 (최우선)
- **`src/images/imagePrompt.builder.js`의 전역 SAFETY_NEGATIVE가 모든 렌더에 'text','logo'를 주입** → Spec Callout Grid·Full Menu Pack·브랜드 라벨 제품 히어로를 **구조적으로 망가뜨림.** 해결: 템플릿별 `look.extra_negative` + `negative_overrides`/예외 플래그로 정보·브랜드 템플릿은 'text'/'logo' 옵트아웃. **텍스트·로고는 모델 생성 말고 결정적 오버레이 레이어로 합성.**
- 템플릿별 `negative_overrides`/`positive_enforcement` 추가: Wrist&Hand='정상 5손가락/단일 손', 립싱크 릴스='입 비동기/치아 모핑/정체성 드리프트', 360='모핑 직물/토핑/패싯'.
- 고위험(Talking-Head, Street Interview, Talking Pet, on-model 360, Wrist&Hand)은 메타에 **'experimental / 게시 전 사람 검수'** 표시 + talking은 1~2문장+B롤로 제한.
- 이미 열려있는 `parent_id`/`editable_slots`(base-variant) 스키마 활용 → 근접 중복을 한 base의 변형으로(예: Editorial Lookbook = On-Model Studio 변형, Blurcore = 룩 속성) → 6개 응집 유지하며 커버리지↑.
- 커머셜 카탈로그마다 **정보 프레임 1개 표준화**(fashion 사이즈표/jewelry 사이징/home 치수/beauty 성분/food 메뉴판) — 단 전부 오버레이 레이어 경유.
- **릴스 사다리 축퇴 수정**: reel=shots×2라 1~2샷(◈2/◈4)이 가능한데 파는 카탈로그가 없어 ◈6 바닥 → 1~2샷 티어 도입(= Kai 리텐션 버그의 근본 원인).

## 3. 한 줄 요약
프롬프트 시드 54개는 즉시 사용 가능한 v1. 단 **"세트 최적화"는 아직** — 핵심은 (1) **빠진 전환 포맷 추가**(정적 UGC·핏/사이즈·before/after·in-hand·메뉴판), (2) **중복 정물 병합**, (3) **온모델/UGC 리프라이스 + 싼 릴스 티어**, (4) **엔진의 전역 text/logo 네거티브를 템플릿별로 분리**(정보·브랜드 템플릿 옵트아웃).
