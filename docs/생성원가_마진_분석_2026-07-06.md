# 생성 원가·마진 분석 (2026-07-06)

목적: 가격 확정을 위한 실제 API 원가 vs Doppia 과금(크레딧) 마진 점검. 
관련: `src/credits/credit.service.js`(과금), `public/js/pricing.js`(판매가).

## 2. Doppia 과금(크레딧) & 판매가

과금(`credit.service.js`): 이미지=`장수×1 + 모델가산`(flash 0/pro 1), 영상=`{5s:8,10s:16}+pro가산2`.
- 4장 flash = **4cr** / 4장 pro = **5cr**(장당 실질 1.25cr) / 5s 릴 = **10cr** / 10s 릴 = **16cr**
판매가(`pricing.js`): 팩 $0.08~0.10/cr · Creator $0.076 · Pro $0.065 · **Brand $0.056**/cr

## 4. 결론 (문제)

1. **🔴 nano-banana-Pro 이미지는 전 플랜 적자.** 장당 실질 1.25cr(~$0.08~0.10) 과금인데 원가 $0.134. 손익분기 = 장당 **2.4cr(Brand 기준)**. 지금은 절반 수준 → 생성할수록 손해.
2. **🟠 릴 10s는 Pro/Brand 플랜 적자**, 릴 5s는 Brand에서 본전. 영상 마진 얇음(모두 Kling Pro 강제라 원가 높음).
3. **🟢 Flash 이미지·팩 결제는 건강**(+30~51%).
4. `pricing.js`의 `estimated:false`("실원가 검증 완료 2026-06-19")는 **틀림** — 위 적자가 검증 안 됨. 코드 원가주석도 옛 것(Runway·flash가만 반영).

## 5. 권장 (40%+ 마진 목표)

- **Pro 이미지 장당 과금 ↑**: 1cr → **3cr/장**(또는 최소 2.5). 손익분기 2.4cr+마진. 구조도 개선: 지금은 "생성당 flat +1cr" → **장당 배수**로(pro 장당 3cr, flash 1cr).
- **릴 과금 ↑ 또는 Std 연결**:
  - 5s 릴 10cr → **14cr**, 10s 16cr → **24~28cr** (전 플랜 40% 마진).
  - 또는 **Kling Standard 연결**($0.084/s, 25%↓)해 기본은 Std·프리미엄만 Pro.
- **Brand 플랜 재검토**: $0.056/cr은 영상·pro이미지 원가 미만. Brand 가격↑ 또는 크레딧 할당(1,400)↓.
- 코드 원가주석·`estimated` 플래그 갱신.
