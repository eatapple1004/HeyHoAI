# Features 전시 구조 (2026-10-15 확정 · 2026-10-16 분담 반영)

사용자(전예담)와 2026-10-13~15 논의로 확정. 힉스필드의 전시 방식을 참고하되, 우리 무기는 모델이 아니라 **워크플로**(제품컷·규격 세트·카톡·운영 대행)라는 전제.
메가메뉴(`public/js/topnav.js` FEAT/SOON_MODELS)·Explore(`public/explore.html`)가 이 문서를 따른다. 바꿀 땐 문서부터.

## 원칙
1. **슬롯은 입력이 다르거나 결과물이 다를 때만.** 같은 입력·같은 엔진에 프롬프트만 다른 건 프리셋(슬롯 안).
2. **무기는 집이 하나.** 상단 nav + Explore 히어로가 집, 다른 곳은 링크만(Image Features의 "Doppia Lens" 행 등). 스킬을 흩뿌리지 않는다.
3. **배선만으로 되는 것 = live, 우리 손이 가는 것 = soon.** 만들 계획이 없는 건 메뉴에 걸지 않는다(백로그에만).
4. **배지**: TOP = 무기(이미지·영상 각 1), NEW = 이번에 여는 것, soon = 미완.
5. 상단 nav 순서 = 만들기(Image·Video·Lens) → 묶기(Pack) → 올리기(KakaoTalk) → 서비스(Works) → 보관(Library).

### Editor 엔진 라우팅 (2026-10-15, 정본 `src/images/imageEdit.engine.js` EDIT_OPS)
연결 엔진 중 **진짜 마스크 입력은 GPT Image(OpenAI images.edit mask)뿐** → 마스크 작업은 GPT 우선. 다른 엔진은 마젠타 표시 이미지로 위치를 알려 준다.
어느 엔진이든 마스크가 있으면 결과를 **원본 위에 마스크 영역만 페더 합성** → 브러시 밖(제품·라벨) 픽셀은 원본 그대로.
| op | 자동 1순위 → 폴백(키 없으면 다음) | 이유 |
|---|---|---|
| replace_bg | Nano Banana Pro → Seedream 5 Pro → FLUX 3 → GPT Image | 제품 보존 + 새 배경에 맞춘 재조명 |
| inpaint · erase · expand | GPT Image → GPT Image 2.5 Flare → Nano Banana Pro | 진짜 마스크 |
| relight | Nano Banana Pro → FLUX 3 → Seedream 5 Pro | 형태·라벨 유지하며 빛만 |
| fix_text | 마스크 有: GPT Image → Nano Banana Pro / 無: Nano Banana Pro → GPT Image | 글자 렌더링 |
| removebg · upscale | BiRefNet · Topaz | 기존 후처리 |
과금 = 고른 엔진 costKey 1장(IMG_CREDIT). 사용자가 패널에서 대안 엔진으로 바꿀 수 있다(Auto 기본). API `POST /api/generate/edit`(multipart image·mask·op·prompt·text·engine·factor·sourceIdx), 카탈로그 = `/api/generate/tools` 의 `editor[]`.
