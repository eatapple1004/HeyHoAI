# Features 전시 구조 (2026-10-15 확정)

사용자(전예담)와 2026-10-13~15 논의로 확정. 힉스필드의 전시 방식을 참고하되, 우리 무기는 모델이 아니라 **워크플로**(제품컷·규격 세트·카톡·운영 대행)라는 전제.
메가메뉴(`public/js/topnav.js` FEAT/SOON_MODELS)·Explore(`public/explore.html`)가 이 문서를 따른다. 바꿀 땐 문서부터.

## 원칙
1. **슬롯은 입력이 다르거나 결과물이 다를 때만.** 같은 입력·같은 엔진에 프롬프트만 다른 건 프리셋(슬롯 안).
2. **무기는 집이 하나.** 상단 nav + Explore 히어로가 집, 다른 곳은 링크만(Image Features의 "Doppia Lens" 행 등). 스킬을 흩뿌리지 않는다.
3. **배선만으로 되는 것 = live, 우리 손이 가는 것 = soon.** 만들 계획이 없는 건 메뉴에 걸지 않는다(백로그에만).
4. **배지**: TOP = 무기(이미지·영상 각 1), NEW = 이번에 여는 것, soon = 미완.
5. 상단 nav 순서 = 만들기(Image·Video·Lens) → 묶기(Pack) → 올리기(KakaoTalk) → 서비스(Works) → 보관(Library).
