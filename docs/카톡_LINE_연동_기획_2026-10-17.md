# 카카오톡 · LINE 연동 기획 (2026-10-17 초안)

사용자(전예담)와 논의 시작. 랜딩·덱의 약속: **"앱도 가입도 프롬프트도 없이, 채팅에 사진을 보내면 컷이 돌아온다."**
전제 사실은 `~/.claude/.../memory/doppia_upgrade_plan_2026_10.md` "카톡 입구 사실(10-09 조사)" + 카카오 정책 확인 항목.

## 1. 한 줄
메신저는 **새 기능이 아니라 입구**다. 안에서 도는 건 지금의 Lens(제품컷)·Shoot(모델컷)·Editor 그대로. 메신저 쪽 코드는 "받기 → 접수 응답 → 비동기 생성 → 돌려주기 → 계정 묶기" 다섯 조각뿐이어야 한다.

## 2. 1차 범위(v1) — 제안
| 항목 | v1 | 이유 |
|---|---|---|
| 입력 | 사진 1장(+ 짧은 글 선택) | 카톡은 여러 장 보내도 첫 장만 온다(실측). 단순할수록 성공률 높음 |
| 메뉴 | ① 제품컷(흰 배경·라이프스타일·화보 중 택1) ② 모델 착용컷(공식 AI 인물 1명 기본) | 둘 다 지금 라이브. 영상은 v2 |
| 결과 | 이미지 1~2장 + "AI로 제작한 이미지입니다" 고지 + 웹에서 더 보기 링크 | 카카오 비즈메시지 가이드 권장 문구 |

## 3. 카카오톡 흐름
```
친구추가 → 환영 메시지(버튼 3: 제품컷 · 모델컷 · 사용법)
→ 사진 전송 → 오픈빌더 스킬 서버 POST(이미지 CDN URL, 10분 유효)
→ 5초 안에 "접수했어요, 30초쯤 걸려요" 응답(스킬 5초 제한)
→ 서버: 이미지 다운로드 → 생성 잡 큐 → 20~60초
→ 결과 전달: (A) 오픈빌더 콜백(지연응답, 신청 필요·확인 중) / (B) 알림톡 이미지 템플릿(건당 유료, 템플릿 검수 1~3영업일)
→ 결과 메시지 버튼: 다시 만들기 · 다른 메뉴 · 웹에서 더(딥링크 /creation?idx=…)
```
- 식별: 카카오 user key(1:1 식별 전용, 마케팅 발송 금지) ↔ Doppia 섀도 계정. 카카오싱크 연결 시 정식 계정과 병합.
- 승인 일정(겹쳐 진행 1~2주): 채널 개설 즉시 → 비즈니스 채널 심사 1~3영업일(법인: 사업자등록증+대표 본인인증) → 챗봇 즉시 → 콜백 신청 확인 → 알림톡 발신프로필+템플릿 1~3영업일 → 카카오싱크.
- 지킬 것: ① "AI로 제작한 이미지입니다" 문구 고정 ② 타인 얼굴 합성 차단(얼굴 1명·성인·실사 판별은 Face swap 코드 재사용) ③ 광고성 발송 없음(정보성 알림톡만).

## 4. LINE 흐름
```
友だち追加 → 리치 메뉴 3칸(商品ショット · モデルショット · 使い方)
→ 이미지 메시지 → Webhook(message id) → GET /v2/bot/message/{id}/content 로 원본 수신
→ reply token(약 1분 유효)으로 "受け付けました、30秒ほど" 응답
→ 생성 → push message 로 이미지 결과(originalContentUrl/previewImageUrl, HTTPS 필수)
```
- 승인: Official Account 개설 즉시(무심사). 인증 배지(認証済アカウント)는 선택, 심사 1~2주. LINE Login 채널은 즉시.
- 비용: push 메시지 월 쿼터 — Communication 플랜 무료 200통/월 · Light ¥5,000 5,000통 · Standard ¥15,000 30,000통(2026 기준, 개설 때 재확인). 결과 1장 = push 1통.
- 일본어 UI는 이번 주 번역한 ja 사전 그대로 쓴다(메뉴·안내문 키 추가).

## 5. 공통 백엔드(둘을 한 구조로)
```
nest/messenger/   (dev 규칙: 4종세트 · 봉투 · DTO · POST 200)
  kakao.controller  POST /api/messenger/kakao/skill   (오픈빌더 스킬)
  line.controller   POST /api/messenger/line/webhook  (서명 검증 X-Line-Signature)
src/messenger/
  inbound.js   채널별 페이로드 → {channel, externalId, imageUrl, text, menu}
  session.js   externalId ↔ shoot/generate 계정(섀도) · 마지막 메뉴 기억(30분)
  jobs.js      큐 + 상태(received → generating → sent/failed) · 재시도 1회
  outbound.js  kakao(callback|alimtalk) · line(push) 어댑터 — 결과 URL은 /images 공개 URL(클라우드플레어 봇 차단 주의 → R2 서명 URL 또는 메신저 CDN 업로드)
테이블: messenger_users(channel, external_id, user_id, menu, free_left, linked_at) · messenger_jobs(id, user, channel, menu, source_url, result_urls, status, error)
```
- 생성은 기존 파이프라인 호출: 제품컷 = Lens 공식 3종, 모델컷 = `POST /api/shoot/models/:id/shot`(공식 AI 인물 1명 + 옷 사진은 Outfit 경로).
- 과금: 섀도 계정에 무료 3장(gift), 이후 웹 크레딧. 메신저 쪽엔 가격 표기만.

## 5-1. 순서 확정(10-17, 사용자): LINE 먼저 → 플로우 검증 → 카톡
- LINE은 개설·Messaging API 모두 심사 없음(인증 배지만 선택 심사 5~10영업일). 카톡 심사(1~2주)는 서류만 먼저 내고 기다린다.
- 테스트 사용자: 일본 쪽 1명 확보. 작업자(대표)가 직접 보며 진행하므로 **안내문·메뉴는 ko·ja 둘 다**(사용자 언어 = LINE 프로필 언어 또는 첫 메시지 언어로 판별, 기본 ja).

## 5-2. 유사 서비스 조사(10-17)
- 직접 경쟁(메신저에 제품 사진 → 제품컷/모델컷 돌려주는 상업 서비스): 한국·일본 모두 **검색으로 확인 안 됨**.
- 인접: 카카오톡 앱 내 "AI로 만들기"(ChatGPT for Kakao, 소비자용 스타일 변환) · 카나나 템플릿(사진→영상) · LINE AI アシスタント 画像編集(사진 보내면 배경 편집·잘라내기, 무료 10회) · LINE Creative Lab URL画像生成(광고주용, URL→광고 이미지) · Draph Art(웹 기반 제품 사진, 한국) · 크몽 외주 상세페이지.
- 함의: "메신저 안 제품 촬영"은 비어 있는 자리. 단, 카카오·LINE 본사가 소비자용 이미지 편집을 이미 넣고 있어 **차별점은 '셀러용 결과물(제품컷·모델컷·채널 규격)'과 '운영까지'** 로 잡아야 한다.

## 7. 덤으로 열리는 것
- 메신저 = **Doppia Works 입구**: "사람이 운영해 줬으면" 버튼 → 진단 6문항 링크. 카톡 상담톡으로 사람이 받는 것도 가능.
- 결과를 받은 사장님이 그대로 올릴 수 있게 v2에서 채널 규격(콘텐츠 팩) 연결.

## 8. 결정이 필요한 것
1. v1 메뉴: 제품컷 3 + 모델컷 1 이 맞는지, 아니면 제품컷만 먼저.
2. 무료 체험 장수(3장 제안)와 그 뒤 유도 방식(웹 로그인 vs 결제 링크 바로).
3. 카톡 결과 전달 기본: 콜백 확인 전까지 알림톡으로 갈지(건당 비용 발생), 콜백 승인 뒤 전환할지.
4. LINE 요금제 시작점(무료 200통으로 시작 → 반응 보고 Light).
5. 카카오 채널 심사 서류(사업자등록증·대표 인증)는 누가 언제 제출할지.
6. 모델컷의 기본 AI 인물 1명을 누구로 할지(남녀 2명으로 가고 메뉴에서 고르게 할지).
