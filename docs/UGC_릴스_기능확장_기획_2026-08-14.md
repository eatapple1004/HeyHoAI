# UGC·릴스 기능 확장 개발기획 — Higgsfield 대비 갭 분석

작성 2026-08-14 · 대상 브랜치 **develop(dev)** · 근거 = `Downloads/힉스필드_개발자인계/clicktoad_개발자_인계.md`(유료계정 실측)

## 0. 결론 세 줄

1. **"전부 모방"은 방향이 틀렸다.** 저쪽은 *단일패스 8초 클립* 아키텍처, 우리는 *조립식 멀티씬*. 우리 쪽이 구조적으로 더 강한 영역(타이밍 강제·자막·음악·**한국어**)을 버리고 저쪽을 따라가면 손해다.
2. **베낄 가치가 있는 건 엔진이 아니라 UX 진입로다.** `URL 하나 넣으면 광고가 나온다`는 흐름, 그리고 재사용 라이브러리(hooks·settings). 엔진은 우리도 같은 걸 부를 수 있고(문서 §부록1) 저쪽은 오히려 역마진 구조다.
3. **최대 승부처는 한국어.** 저쪽은 한국어로 입력해도 `prompt_language: "en"` 고정, 대사·컴파일 전부 영어(문서 §8). 한국 커머스 시장에서 이건 결정적 결함이고 우리가 이미 이기고 있다.

## 1. 아키텍처 비교

| | Higgsfield Click to Ad | Doppia 현재 |
|---|---|---|
| 구조 | **단일 잡** `marketing_studio_video` | 조립식: 대본 → 씬별 이미지 → 씬별 모션 → ffmpeg 합성 |
| 대본 | 서버 프롬프트 컴파일러(Hermes Agent, 비공개) | `src/ugc/ugcScript.service.js` (Claude, 구조화 스키마) |
| 영상 | Seedance 2.x 단일패스(모션+오디오+발화) | `clipPipeline.service.js` → nanoBanana + Kling/Minimax/Runway |
| 오디오 | 모델이 같이 생성 | TTS + 음악 별도 트랙(`src/ugc/audio/`) |
| 자막 | 없음(모델이 그리는 화면 텍스트뿐) | ffmpeg 확정 렌더 |
| 길이 제어 | **요청일 뿐 강제 아님** (실측: duration 8인데 11초 9컷 계획을 뱉음) | 씬 단위 확정 |
| 언어 | 영어 고정 | 한국어 1급 |

## 3. 단계별 로드맵

### Phase 1 — ANGLE LOCK 이식 (1일, 즉시)
문서 §5가 지목한 즉시 이식 가능 기법. 레퍼런스에 없는 각도를 모델이 지어내는 문제의 해법이다.

- 대상: `src/pack/refBake.service.js`, `src/ugc/clipPipeline.service.js`
- 내용: 제품 레퍼런스가 있을 때 프롬프트에 각도 고정 절 추가
  > "@Image1에 보이는 면만 노출. 안 보이는 면이 드러나게 회전 금지."
- **기법이지 저쪽 템플릿 원문이 아니다** — 우리 문장으로 작성
- 검증: 동일 제품 10회 생성 → 각도 이탈률 before/after

### Phase 2 — 진입로: URL → 광고 (1~2주) ★최우선
저쪽 Click to Ad의 본질은 모델이 아니라 **"URL 하나면 끝"** 이라는 진입 마찰 제거다.

```
POST /api/ugc/from-url  { url }
  ① 제품 페이지 뷰포트 스크린샷(모바일/데스크톱)  ← Playwright, 텍스트 스크레이핑 아님
  ② 이미지+텍스트에서 제품 속성 추출(Claude)
  ③ 브랜드킷 자동 추출(색·폰트·로고·톤) → brand_kits upsert
  ④ 기존 ugcScript.generateUgcScript()로 대본
  ⑤ 기존 파이프라인 그대로
```
- 신규: `nest/ugc/` (컨트롤러·서비스·리포지토리) — **레거시 아님, Nest에 만든다**
- 재사용: 스크린샷은 이미 Chrome 렌더 인프라가 있으므로 그 위에 얹는다
- 검증: 쿠팡·스마트스토어·자사몰 각 5개 URL로 성공률 측정

### Phase 3 — 재사용 라이브러리 (1주)
hooks·settings를 **한 테이블 + type 구분**으로 만든다(저쪽도 동일 구조, §8).

```sql
CREATE TABLE ugc_setup_items (
  id UUID PRIMARY KEY,
  type TEXT NOT NULL,          -- 'hook' | 'setting'
  name TEXT NOT NULL,
  prompt TEXT NOT NULL,
  locale TEXT DEFAULT 'ko',    -- 🔑 한국어 훅이 우리 차별점
  is_official BOOLEAN DEFAULT false,
  user_id UUID,                -- null = 공식 시드
  created_at TIMESTAMPTZ DEFAULT now()
);
```
- 공식 시드: 한국어 훅 20개(저쪽 9개, 전부 영어) + 장소 15개
- **기존 규칙 준수**: 시드 하드코딩과 동시에 Excel/CSV export (CLAUDE.md 📊)
- 사용자가 자기 훅을 저장·재사용 → 마켓플레이스 판매까지 연결 가능

### Phase 4 — 프롬프트 컴파일러 분리 + enhance-only (1주)
지금 프롬프트 조립이 파이프라인 안에 흩어져 있다. 저쪽 Hermes Agent에 대응하는 **단일 컴파일 계층**으로 뽑는다.

```
nest/ugc/prompt-compiler.service.ts
  compile(input) → { enhancedPrompt, shots[], technical, constraints }
```
- `POST /api/ugc/compile` — 생성 없이 컴파일 결과만 반환(크레딧 0)
- 효과: ①품질 디버깅이 가능해진다 ②실패 시 재생성 비용 절감 ③A/B 테스트 가능

### Phase 5 — 단일패스 모델 옵션 (후순위, 검증 후)
Seedance 2.x를 프로바이더로 추가해 **짧은 8초 광고**만 단일패스로 라우팅.
- 조건: 원가 검증 먼저. 저쪽 8초/720p 40크레딧 판매 vs seedance 52 = 역마진(§부록1)
- 우리 조립식이 더 싸면 굳이 갈 이유 없다 → **원가 비교 후 결정**

## 4. 하지 않을 것 (명시)

| 항목 | 이유 |
|---|---|
| 저쪽 프롬프트 템플릿 원문 이식 | 확보하지도 못했고(Hermes 비공개), 해자도 아니다 |
| ad-formats 42종 복제 | 실측 결과 전부 `type: headline`(이미지 광고용), 영상과 무관 + 중복·내부항목 누수 |
| 영어 우선 설계 | 우리 시장은 한국. 저쪽 결함을 따라할 이유 없음 |
| 8초 고정 | 릴스는 15~30초가 주력. 우리 씬 조립이 유리 |

## 5. 검증 기준

| Phase | 지표 |
|---|---|
| 1 | 각도 이탈률 (10회 생성 기준) |
| 2 | URL→영상 성공률 ≥ 80% (쿠팡·스마트스토어·자사몰 15개) |
| 3 | 훅 재사용률, 생성 소요시간 단축폭 |
| 4 | 재생성률 감소폭, 컴파일 응답 < 3초 |
| 5 | 8초 광고 원가 비교 (조립식 vs 단일패스) |

## 6. 작업 규칙

- 브랜치 `develop`, 신규 API는 **`nest/`에** (CLAUDE.md 🧩) — `NEST_PREFIXES` 등록 필수
- 시드/프롬프트는 **JS 시드 + 구조화 export 동시** (CLAUDE.md 📊)
- 배포 후 `scripts/nest_parity_check.js` — 단 **신규 도메인은 parity 대상 아님**(레거시에 대응 라우트 없음)
- PR마다 origin/main 동기화 선행

## 7. 법적 검토 필요 (개발 착수 전)

기능·아이디어 모방은 일반적으로 문제되지 않지만, 다음 두 가지는 확인이 필요하다.

1. **Higgsfield ToS의 경쟁제품 개발 제한 조항** — 유료 계정으로 API를 관찰해 경쟁 제품을 만드는 행위를 금지하는 조항이 있는지. `--enhance-only`로 계속 모니터링하자는 §부록3 제안은 특히 이 조항에 걸릴 소지가 있다.
2. **컴파일된 프롬프트 원문의 취급** — `jobs.json`의 `enhanced_prompt`는 저쪽 저작물로 볼 여지가 있다. **기법(ANGLE LOCK 같은 구조적 아이디어)은 자유롭게 쓰되, 문장을 그대로 옮기지 않는다**는 원칙을 코드 리뷰에서 강제할 것.

이 문서와 원시 덤프는 사내 참고용으로만 두고 배포물에 포함하지 않는다.
