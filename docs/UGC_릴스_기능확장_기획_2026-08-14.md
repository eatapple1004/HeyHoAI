작성 2026-08-14 · 대상 브랜치 **develop(dev)**
목표 = `higgsfield.ai/marketing-studio?tool=url-to-ad` 기능을 Doppia에 **그대로 구현**
근거 = `Downloads/힉스필드_개발자인계/`(유료계정 CLI 실측) + fal.ai 공식 스펙

## 1. 저쪽 흐름 해부

```
[URL 입력]
   ↓ webproducts fetch --url
   ├─ 제품 페이지를 뷰포트별 스크린샷 캡처   ← 텍스트 스크레이핑 아님(실측 확인)
   └─ brand-kits fetch --url
        색 · 폰트 · 로고 + industry · keywords · business_overview · tone_of_voice · SNS
   ↓ 조합 (선택 UI)
   mode(25종) · hook_id · setting_id · avatar_ids · web_product_ids
   ↓ 서버 프롬프트 컴파일러 "Hermes Agent"  ← 저쪽 유일 자산
   enhanced_prompt = REFERENCE BLOCK / LOCATION / PROMPT(타임코드 샷) / TECHNICAL BLOCK
   ↓ 단일 잡  marketing_studio_video
   [8초 720p 9:16 영상 + 오디오]
```

**CEL 규칙 2개** (그대로 이식)
```
ad_reference_id == null || (hook_id == null && setting_id == null)
size(product_ids) == 0 || size(web_product_ids) == 0
```

`specific_mode` 는 URL 경로일 때 `web_product`.

## 2. 엔진 조달 — 확정

`marketing_studio_video`는 **ByteDance Seedance의 얇은 래퍼**다. 확정 근거:

| | Higgsfield 실측 | fal.ai Seedance 2.0 공식 |
|---|---|---|
| aspect_ratio | auto·21:9·16:9·4:3·1:1·3:4·9:16 | **동일 7종** |
| duration | 기본 15 | 4~15 (auto) |
| resolution | 480p/720p/1080p | 동일 |
| generate_audio | bool | 동일(음악·SFX·립싱크 포함) |

파라미터 목록이 일치한다. 저쪽 공식 문구도 *"Powered by Seedance 2.0"*.

**→ 우리도 같은 엔진을 직접 부를 수 있다.** fal.ai가 정식 제공사이고 `FAL_API_KEY`는 이미 보유 중.

```
bytedance/seedance-2.0/image-to-video        표준
bytedance/seedance-2.0/fast/image-to-video   저가 티어
bytedance/seedance-2.0/reference-to-video    레퍼런스 주입(제품+모델)
bytedance/seedance-2.5/reference-to-video    레퍼 50개·30초
```

`reference-to-video`가 URL to Ad에 가장 맞는다 — 제품 이미지 + 아바타를 동시에 넣는 구조.

## 3. ⚠️ 원가 — 착수 전 결정 필요

| | 초당 원가 | 8초 원가 | 크레딧 환산(×1,361) |
|---|---|---|---|
| Seedance 2.0 표준 | $0.3024 | **$2.42** | **3,294** |
| Seedance 2.0 fast | $0.2419 | $1.94 | 2,640 |
| **우리 현재 Ad Video high 10초** | — | **$1.25** | 1,705 |
| (참고) Kling v3 Pro | $0.112 | — | — |

**Seedance는 Kling 대비 초당 2.2~2.7배다.** 그대로 모방하면:

- 8초 광고 1편 판매가가 **최소 2,640~3,294 크레딧** (현재 10초 조립식 1,705의 **2배**)
- Standard 플랜(20,300cr/월)으로 **월 6~7편**밖에 못 만든다
- 저쪽은 이걸 40크레딧에 판다 → 저쪽 크레딧 단가가 우리와 다르거나, **역마진이거나, 실제로는 싼 엔진으로 라우팅** 중(잡 레코드에 엔진 필드가 없어 확인 불가 — 실측)

**선택지 (제품 결정)**

| 안 | 내용 | 결과 |
|---|---|---|
| **A. 충실 복제** | Seedance 단일패스 그대로 | 저쪽과 동일 품질·구조. 원가 2배, 판매가 인상 필요 |
| **B. UX만 복제** | URL→광고 흐름은 동일, 엔진은 우리 조립식 | 원가 유지. 8초 단일샷 특유의 물리·립싱크는 못 따라감 |
| **C. 엔진 라우팅** | 사용자에게 "빠른/정밀" 선택 노출, 내부 라우팅 | 저쪽이 하는 방식. 구현 최다 |

기본은 **A(충실 복제)** 로 잡고, 프로바이더 계층에서 B 전환이 가능하도록 짠다.

## 4. 구현 스펙

### 4-1. 데이터 모델 (신규)

```sql
-- 웹제품: URL에서 수집한 제품
CREATE TABLE web_products (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL,
  url TEXT NOT NULL,
  name TEXT,
  description TEXT,
  price TEXT,
  screenshots JSONB DEFAULT '[]',   -- [{viewport:'mobile'|'desktop', url}]
  images JSONB DEFAULT '[]',        -- 추출된 제품 이미지
  attributes JSONB DEFAULT '{}',    -- Claude vision 추출: 카테고리·소재·색·셀링포인트
  status TEXT DEFAULT 'pending',    -- pending|ready|failed  (비동기)
  created_at TIMESTAMPTZ DEFAULT now()
);

-- 훅·장소: 저쪽과 동일하게 한 테이블 + type 구분(MarketingSetupItem)
CREATE TABLE ad_setup_items (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  type TEXT NOT NULL,               -- 'hook' | 'setting'
  name TEXT NOT NULL,
  prompt TEXT NOT NULL,
  locale TEXT DEFAULT 'ko',
  is_official BOOLEAN DEFAULT false,
  user_id UUID,                     -- null = 공식 시드
  sort_order INT DEFAULT 0
);

-- 광고 잡
CREATE TABLE ad_jobs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL, team_id UUID,
  mode TEXT DEFAULT 'ugc',
  specific_mode TEXT DEFAULT 'web_product',
  web_product_id UUID, hook_id UUID, setting_id UUID,
  avatar_ids JSONB DEFAULT '[]',
  duration INT DEFAULT 8, resolution TEXT DEFAULT '720p',
  aspect_ratio TEXT DEFAULT '9:16', generate_audio BOOLEAN DEFAULT true,
  enhanced_prompt TEXT,             -- 컴파일 결과 보존 = 품질 회귀 추적의 핵심
  engine TEXT,                      -- 🔑 저쪽은 숨겼지만 우리는 남긴다
  status TEXT DEFAULT 'pending',
  result_url TEXT, error TEXT,
  charged INT DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT now(), finished_at TIMESTAMPTZ
);
```

`brand_kits` 확장: `industry` `keywords` `business_overview` `tone_of_voice` `website_url` `sns` 컬럼 추가
(현재 `logo_url`·`primary_color`·`font_name`뿐).

### 4-2. API (전부 `nest/ad-studio/`)

```
POST   /api/ad-studio/web-products        { url }        → 비동기 수집 시작
GET    /api/ad-studio/web-products/:id                   → 상태·결과
GET    /api/ad-studio/hooks                              → 훅 라이브러리
GET    /api/ad-studio/settings                           → 장소 라이브러리
POST   /api/ad-studio/brand-kit/fetch     { url }        → 브랜드킷 자동 추출
POST   /api/ad-studio/compile             {...}          → 🔑 enhance-only (크레딧 0)
POST   /api/ad-studio/cost                {...}          → 비용 산정 (무료)
POST   /api/ad-studio/jobs                {...}          → 생성 (CEL 규칙 검증)
GET    /api/ad-studio/jobs/:id                           → 폴링
```

⚠️ `NEST_PREFIXES`에 `/api/ad-studio` 등록 필수.

### 4-3. 수집기 (webproducts fetch)

- **Playwright** 신규 도입 (현재 미보유 — Chrome 렌더는 있으나 헤드리스 스크래핑용 아님)
- 뷰포트 2종: `390×844`(모바일) · `1440×900`(데스크톱)
- 추출: og:image · 본문 주요 이미지 상위 6장 · 가격 텍스트
- **스크린샷을 Claude vision에 태워** 제품 속성 구조화 (텍스트 파싱보다 쇼핑몰 대응력이 높다 — 저쪽이 이 방식을 쓰는 이유)
- 실패 대비: 로그인 벽·봇 차단 시 `status=failed` + 수동 이미지 업로드 폴백

### 4-4. 프롬프트 컴파일러 (우리판 Hermes)

`nest/ad-studio/prompt-compiler.service.ts` — 저쪽 4블록 구조를 **우리 문장으로** 재구현.

```
[REFERENCE BLOCK]  아바타 외모 고정 + "얼굴·외형만 참조, 배경 복제 금지"
[ANGLE LOCK]       🔑 "@Image1에 보이는 면만 노출. 안 보이는 면이 드러나게 회전 금지."
[LOCATION]         setting에서
[SHOTS]            SHOT [00:00–00:02] … 대사 포함
[TECHNICAL]        Lens / Sensor / Stabilization / Audio
```

- **한국어 대사 생성** — 저쪽은 `prompt_language: "en"` 고정이라 한국어 입력도 영어로 나온다. 우리는 한국어 그대로.
- 컴파일 결과를 `ad_jobs.enhanced_prompt`에 항상 저장.

### 4-5. UI

`public/ad-studio.html` 신규 — URL 입력 → 수집 결과 확인 → mode/hook/setting/avatar 선택 → 미리보기(compile) → 생성.
mode 그리드는 저쪽 25종 UI를 참고하되 **우리가 실제 지원하는 것만** 노출(허수 금지).

## 6. 저쪽 결함 — 따라하지 않을 것

실측에서 확인된 것들. 복제하되 이 부분은 고친다.

| 저쪽 결함 | 우리 처리 |
|---|---|
| duration 8 요청에 11초 9컷 계획 컴파일(제약 위반) | 컴파일 후 **타임코드 합계 검증**, 초과 시 재컴파일 |
| 잡 레코드에 엔진 필드 없음 | `ad_jobs.engine` 기록 — 품질 회귀 추적에 필수 |
| 한국어 입력 → 영어 출력 | 한국어 유지 |
| ad-formats 42종에 중복·내부항목(`librarian`·`picker`) 누수 | 시드 검수 |
| A+ 모듈이 글자 크기를 말로 지시 → 한글 깨짐 | 텍스트는 CSS 확정 렌더(기존 방식 유지) |

## 7. 미확정 (조사 필요)

1. **저쪽 크레딧 단가** — 40크레딧이 얼마인지 모르면 가격 비교가 불가. 저쪽 요금제 확인 필요.
2. **mode 25종의 정확한 문자열** — UI 라벨만 확보. 서버가 검증하지 않아 임의 문자열도 통과(실측)하므로, 우리는 **우리 모드를 정의**하면 된다.
3. **Seedance 2.5 전환 여부** — 2.5는 레퍼 50개·30초 지원. 릴스 길이(15~30초)에 더 맞을 수 있어 Phase 0에서 같이 검증.
4. **fal 리전·쿼터** — 동시 생성 한도, 한국에서의 지연.

## 8. 법적 검토 (착수 전)

- Higgsfield ToS의 **경쟁제품 개발 제한 조항** 유무 확인. 특히 `--enhance-only`로 저쪽 템플릿 출력을 지속 관찰하자는 제안은 이 조항에 걸릴 소지가 크다 → **이 문서에서는 채택하지 않는다.**
- 컴파일된 프롬프트 원문(`jobs.json`의 `enhanced_prompt`)은 저쪽 저작물로 볼 여지가 있다. **구조·기법은 자유롭게 쓰되 문장을 그대로 옮기지 않는다** — 코드 리뷰에서 강제.
- 원시 덤프와 이 문서는 사내 참고용. 배포물·공개 저장소에 포함하지 않는다.
