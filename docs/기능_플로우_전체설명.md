# Doppia — 전체 기능·플로우 설명 (현재 상태, 2026-06-08)

> 이 문서는 **개발자도, 비개발자도** 제품 전체를 말로 이해할 수 있게 쓴 설명서입니다.
> 현재는 **프론트엔드 mock**(백엔드 연결 전) — 생성·결제·크레딧·게이팅은 화면 동작만 있고 실제 서버는 `docs/BACKEND_HANDOFF.md` 참고.

## 한 줄 요약
**셀카(인플루언서) 또는 제품 사진(브랜드) 1장 + 템플릿 선택 → 스튜디오급 사진/릴스 자동 생성.** 프롬프트 작성 0. 사용량은 "크레딧(◈)"으로 차감. 무료로 시작, 구독/충전으로 확장.

## A. 전 페이지 공통 (공유 시스템)

- **네비게이션**: 모든 페이지 상단에 Studio · Market · Gallery · Billing · Business + 크레딧 잔액 + `+ Buy`.
- **`js/hh.js` (공유 상태)**: 크레딧 잔액(브라우저 localStorage, 신규 10◈), 현재 플랜(free/creator/pro/brand), 토스트 알림, 첫 방문 시각(24h 오퍼 계산용). 모든 페이지의 크레딧 칩을 한 값으로 동기화.
- **`js/pricing.js` (가격 정본)**: 모든 가격(플랜·팩·팀·할인율)이 **이 파일 한 곳**에서 나옴. landing·billing·studio가 전부 여기서 읽음 → 가격 바꿀 땐 여기만 수정. (백엔드 연결 시 `GET /api/pricing`로 대체.)
- **톤**: 다크 퍼플 프리미엄(`css/theme.css`).

## B. 페이지별 기능·플로우

### 1) landing.html — 마케팅 입구
- **청중 토글** (Creators / Brands & Sellers / Business): 누르면 히어로 문구·CTA가 그 대상에 맞게 바뀜.
- **소셜 프루프**: 12,000+ 크리에이터 · 2.4M 게시물 · 4.9★ · 7개 산업 스탯 + 모델 로고스트립.
- **가격표 4카드**: Free / Creator $19 / **Pro $39(Most popular)** / Brand $79 — 숫자는 pricing.js에서 채움.
- **진입 동선(중요)**: "Start free / Create / Get started" 등 주요 CTA는 **곧장 /studio.html**(가치 먼저 체험). "Log in"만 로그인 페이지로. 버티컬 칩(예: Food & Cafe)은 studio의 해당 모드로 딥링크.
- 하단: 브랜드/셀러 카드, 작동방식 3단계, 푸터(Business/White-label/Affiliate 링크).

### 2) saas-login.html — 가입/로그인 (mock)
- Google 버튼 최상단, 이메일 폼은 그 아래. 가입은 약관 1체크만. 현재는 **무엇을 넣든 성공 처리 → /studio.html**. (실제 인증은 개발자 auth로 연결.)

### 3) studio.html — 핵심 생성 화면
**모드 3종**: 😎 인플루언서(셀카) / 🛍️ 제품(7버티컬: Fashion·Beauty·Jewelry·Food·Home·Tech·Pet) / 📢 UGC 광고.

**단계 흐름**:
1. **Subject**: 얼굴/제품 사진 업로드 또는 샘플 선택. (UGC는 스포크스퍼슨: 내 얼굴/AI 아바타 + 스크립트 작성 단계 추가.)
2. **템플릿 선택**: 모드·버티컬별 맞춤 카탈로그. **★ Best value 배지**가 "크레딧당 산출물 최고" 템플릿을 추천(이유 표기).
3. **생성 바**(하단 고정, 모바일은 ⚙ Options로 접힘):
   - 품질: Standard / HD(+1) / 4K(+2)
   - 🚫 워터마크 제거(+1) · ⚡ Priority(+1) · 📝 캡션+해시태그(+1, 6개국어 선택)
   - (UGC만) A/B 변형: ×1/×3/×5/**×10/×25** — 변형당 비용 배수
   - 실시간 총 비용 표시 → **Generate**
4. **결과 카드**: 사진/릴스 미리보기 + Download/Post.

**크레딧 부족 시 — 인라인 페이월**: "필요 ◈ / 부족분" 표시 + 3옵션 — **◈50 $5(소액, 부족분 작을 때만)** / ◈220 $18(+자동충전) / **추천 티어 구독**(아래 라우팅). 결제 후 그 자리에서 생성 재개.

**결과 직후 수익화(티어 라우팅이 핵심)**:
- **워터마크 정책**: 무료 사용자는 **첫 결과 1개는 깨끗**, 이후 결과에 워터마크. 제거는 ◈1(단발) 또는 구독.
- **업셀 배너 — `recommendTier()`가 작업 신호로 분기**:
  - 워터마크/기본 → **Creator $19**
  - 4K·브랜드킷·캡션·반복·스트릭 → **Pro $39**
  - 대량 광고 변형(×10↑) → **Brand $79**
  - 제품/UGC(상업 의도) → 위 권유에 더해 **"광고·판매엔 상업 라이선스 → Brand" 컨텍스트 칩**(돈 벽을 모드 선택 순간이 아니라 의도 시점에 제시)
- **next-action**: ↺ Make another · ⬆ Upscale to 4K(→Pro) · 🗓 **주간 세트**(이 룩을 7일치 게시물로, 20% 묶음 할인).
- **캡션 블록**: 켜면 결과 아래 버티컬·모드 맞춤 캡션+해시태그(6개국어) + 복사.

**리텐션 장치**: 🔥 연속 생성 스트릭 + 데일리 보너스 크레딧(**첫 성공 이후** 재방문에만 모달). 상단에 현재 플랜 칩.

**브랜드킷 모달**(Pro 기능): 로고·컬러·폰트 저장 → 결과물에 브랜드 적용.

### 4) gallery.html — 내 보관함
- 생성한 사진/릴스 그리드 + 필터(All/Photos/Reels/...).
- **사진 → 릴스 조립**: "🎬 Make a reel" → 사진 다중 선택 → 릴스 템플릿+음악 선택 → 9:16 미리보기 → 갤러리에 새 릴스 추가(◈1). (풀 편집기 아님 = "조합 자동화".)
- **빈 상태 재방문 훅**: 첫 결과 워터마크-프리 안내 + 스트릭/주간세트/48템플릿 후크 카드.

### 5) billing.html — 결제·크레딧
- 현재 플랜·잔액. **첫 24h 50% 오퍼 배너**(가짜 상시 X → 가입 후 24h 실제 카운트다운, 만료 시 숨김).
- 월/연 토글(연 20%↓). **4플랜 카드**(Free/Creator/Pro/Brand, pricing.js) + 라이선스 표기(Personal/Commercial).
- **Team 밴드** $199(3좌석·공유풀◈2,000·+$15/좌석) → "Join Team beta" 리드폼.
- **크레딧 팩** 4종(◈50 $5 … ◈1,750 $110, 볼륨 할인) + "구독이 항상 더 싸다" 안내(카니발 방지).
- "What credits buy" 코스트표 · 자동충전 토글.
- **구독 관리**: ⏸ Pause(권장) / Cancel — Cancel 누르면 가두는 confirm 대신 **명확한 박스**(Pause 추천 / Cancel anyway).

### 6) marketplace.html — 양면 시장 (공급측)
- **Become a creator** → 신청 모달(핸들·판매유형·카테고리·샘플 업로드·제출 → 심사 확인). 70% 수익 배분.
- **Templates 탭**: 크리에이터 양식(평점·사용수·@핸들·◈가격).
- **Virtual Models 탭**: 공식 Doppia 모델 10종. **Standard**(◈/회·비독점) vs **Exclusive**($/월·나에게 독점) 라이선스 계층 설명 + Official 배지.
- Creator earnings / affiliate 진입 링크.

### 7) earnings.html — 크리에이터 수익 허브
- 누적/이번달 수익·대기 정산·라이브 항목 수 스탯 + 게시한 템플릿/모델별 사용수·수익·상태(Live/In review) 테이블 + 정산 정보(70% 분배).

### 8) affiliate.html — 추천 프로그램
- 내 추천 링크 복사 + 실적 4스탯 + 3단계 안내 + 30% 12개월 반복 커미션·지급 정보.

### 9) business.html — B2B (5탭)
- **🔌 API & Shopify**: API 키(마스킹/재발급)·코드 샘플·사용량 미터·Shopify 설치·카탈로그 벌크.
- **👥 Team**: 멤버(역할 Owner/Editor/Viewer)·공유 크레딧 풀(◈2,000)·좌석 추가/풀 증액.
- **🏷️ White-label**: **4티어 셀프서비스**(Agency Lite $199 / Starter $499 / Growth $999 / Scale $1,999) + 14일 트라이얼 셀프 체크아웃 + **마진 시뮬레이터**(청구액·사용량 입력 → 내 마진 계산), 30+ 클라는 Talk to sales.
- **🗂️ Private library**: 에이전시 전용 비공개 템플릿/브랜드킷(팀 공유, 마켓 비공개).
- **📅 Schedule & Analytics**: 성과 스탯·7일 차트·콘텐츠 캘린더.

## C. 수익화 구조 (전체 그림)
- **플랜 사다리**: Free(10◈ 1회) → Creator $19(250◈) → **Pro $39(600◈)** → Brand $79(1,400◈) → Team $199 → White-label $199~1,999.
- **단발 수익**: 크레딧 팩(소액 $5 ~ 대형 $110), 결과 단발 보정(◈1).
- **양면 시장**: 마켓 70/30 분배 + 공식 가상모델 라이선스(자사 100%).
- **전환 장치**: 인라인 페이월 · 결과 순간 **티어 라우팅** 업셀 · 워터마크 · 24h 첫결제 오퍼.
- **리텐션/확장**: 스트릭·데일리 보너스 · 주간 세트 · 자동충전 · Pause(이탈 방어) · 좌석/플랜 업그레이드.
- 설계 의도: 인플루언서=유입/바이럴, 브랜드/UGC=실매출, 프로바이더 라우팅·모델 티어링=마진 방어.

## D. 지금 "동작"하는 것 vs 백엔드 필요
- **동작(mock)**: 모든 화면·플로우·상태 전이·비용 계산·티어 라우팅·크레딧 차감(브라우저), 캡션/주간세트/마켓/B2B UI.
- **백엔드 필요(실제)**: 진짜 이미지/영상 생성, 업로드 처리, 결제(Stripe), 크레딧 서버 원장, 플랜 게이팅 강제, 상업 라이선스 발급, 마켓 정산, 팀/화이트라벨 프로비저닝, 실제 가격(=/api/pricing). → `docs/BACKEND_HANDOFF.md`.
