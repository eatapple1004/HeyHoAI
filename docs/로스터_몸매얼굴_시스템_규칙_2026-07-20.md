# Doppia 로스터 — 몸매·얼굴 시스템 확정 규칙 (2026-07-20)

이 문서 = 로스터 재구축(남녀 각 100 + kids)·`build_model_roster.js` 배선의 **정본**. 세션 검증으로 확정됨.

## A. 전체 구조
1. 로스터 = 모델당 **{정면 얼굴 이미지(스왑 소스 겸 픽커 썸네일) + 페르소나 텍스트 레코드}**.
2. **페르소나 레코드 = single source of truth.** 얼굴·제품 생성 프롬프트는 레코드에서 **코드로 파생**(손 타이핑 금지 → 드리프트/오타 방지). 파일럿서 손타이핑 makeup 오타로 "다른 사람" 나온 사고 있었음.

## B. 페르소나 스키마
- identity: id·name·gender·descent·ethnicity_group·age
- body: `body_type` → 크로키 + 볼륨텍스트로 파생
- face: face_shape·features(눈·코·입·턱)·eye_color·marks
- surface: skin_tone·skin_texture(항상 최상=light texture)·hair(스타일+색, descent 개연범위)
- character: vibe·makeup(여성만)

## C. 얼굴 생성 규칙 (로스터 얼굴 = 스왑 소스)
1. **미모**: 극상. realism 강가드 제거(부정어 최소) + **light texture 한 줄**(플라스틱만 방지). **best-of-N**(슬롯당 6~8 → 상위 선별)이 실질 천장. *더 밀면 sameface·플라스틱·진정성↓.*
2. **각도 = 정면 고정** / **표정 = 다양(닫은입 범위)** — 스왑 안전 + 픽커 다채. (표정은 소스에 박혀 제품에도 반영)
3. **no text/logo/watermark** 명시(매거진 텍스트 아티팩트 방지). *예외: L5 순긍정 실험은 부정어 생략.*
4. **anti-sameface**: 이목구비·머리·마크·화장·바이브 변주.
5. **body_type은 "빌드 형용사 한 줄"로만 얼굴에 반영**(목·어깨·살집 일치). **크로키(전신)는 얼굴 생성에 안 씀.**

## D. 몸매(크로키) 규칙
1. 크로키 = body_type별 라인아트. **크로키는 gemini가 정규화하니, 그 크로키를 만든 볼륨텍스트를 stage-1에 반드시 co-inject.**(이미지만은 볼륨 깎임)
2. **여성 비율**: 이상형 slim-thick **50%**(크로키 p_h·p_i·r4·t3, 순환) / 슬랜더-골격형 **30%**(sf5·sf6) / 서구형 볼륨 **20%**(wx3·wx5).
3. **남성 비율**: 슬랜더 **30%**(m_slx4) / fit-v6f **40%** / fit-v3f **30%**. (fit = V-taper 골격개선[넓은어깨·긴팔·긴다리·장신] + MID 체지방[복근 뚜렷·자연핏, shredded/vascular 아님])
4. 확정 크로키 원본 = `~/doppia-underwear/tmp/croquis-confirmed/` (ideal_p_h/p_i/r4/t3 · slender_sf5/sf6 · western_wx3/wx5 · m_slender_slx4 · m_ideal_v6f/v3f).
5. 각 body_type의 볼륨텍스트 전문 = `tmp/gen_b25_onmodel.js`(F_CORE+EXTRA·F_SLENDER·WTEXT·M_FIT·M_SLENDER) 참조.

## E. 제품 온모델 파이프라인 (성별·품목별)
| | Stage-1 입력 | 마감 |
|---|---|---|
| **일반 의류** | 페르소나 텍스트 + **얼굴 ref 이미지**(허용) + 배경 + 크로키·볼륨텍스트 | **스왑 없음**(gemini 단일) |
| **속옷** | 페르소나 텍스트 + 배경 + 크로키·볼륨텍스트 (얼굴 ref X=벤더/gemini 차단) | **facefusion 스왑 → 질감복원** |
- stage-1 얼굴 = **페르소나 max 서술**(형·이목구비·**화장**·스킨·머리). ⚠️**스왑이 화장을 안 옮기니 화장을 stage-1 베이스에 반드시 주입**(안 하면 로스터=글램인데 제품=소프트).
- **스킨톤은 얼굴·몸 일치**(단차 제거).

## F. 스왑 엔진 + 복원
1. **"B+경계"**: `inswapper_128 + boost512 + face-mask-blur 0.6 + face-mask-types "box occlusion"` (인핸서·combo OFF). pm2 faceswap-worker 상시(facefusion=~/facefusion).
2. **질감복원**: `scripts/freq_combine.py <swapped> <base> <out> 7 100 1.2` — 스왑이 뭉갠 피부결을 **베이스 실사에서**(고주파) 복원. 인핸서 날조가 아니라 실사 → anti-AI티. 워커에 스왑 직후 1패스 추가 예정.
3. 배치 실무: **자동 재시도**(gemini 세이프티 간헐 NO IMAGE) · facefusion은 **target=output 확장자 일치 필수**(.jpg, sips 변환).

## G. 핵심 원칙 (왜)
- 베이스를 소스 닮게(max-text) → 스왑이 미세 정체성만 고침 = 이음매 없음.
- **크로키=몸 / 텍스트=얼굴** 분담 → 프롬프트 예산 안 싸움(둘 다 max).
- 볼륨은 크로키만으론 정규화됨 → **볼륨텍스트 co-inject 필수**.
- 미모는 realism 가드가 눌렀던 것 → best-of-N이 천장.
- 한글 파일명 NFD/NFC → node/find 못 읽음, 크기/glob로 우회.
