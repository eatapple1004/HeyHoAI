## ⚠️ AI 난이도 / 🅣 텍스트 오버레이
- **손가락**(주얼리 착용·테크 인핸드·패션 온모델·인플 haul) → 부분 크롭 + 5손가락 negative.
- **말하는 입**(UGC 토킹 5종·토킹펫) → 샷당 1~2문장 + B롤, 립싱크 negative, 사람검수.
- **before/after 정체성**(뷰티) → 동일 인물 락, 광고 컴플라이언스 검수.
- **🅣 글자 오버레이 의존**(패션 사이즈·푸드 메뉴·테크 스펙·홈 치수·주얼리 사이징·펫/General 패키징·General 플랫레이·UGC 헤드라인 등) → AI가 글자 안 그림, **오버레이 레이어로 합성**(엔진 `text_overlay` 소비 필요).
- **헤드샷**: 얼굴 identity_lock·어깨 크롭이라 손/글자 리스크 최소. 릴은 미세 모션만(립싱크·큰 회전 금지)으로 morph 회피.
