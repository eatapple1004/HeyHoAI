# 힉스필드 Marketing Studio — 프로세스 분석과 모방 계획 (2026-08-17)

경쟁사 higgsfield.ai의 **Marketing Studio Video**가 어떤 과정을 거치는지 정리하고,
우리가 무엇을 이미 갖고 있으며 무엇을 만들어야 하는지 매핑한다.

근거는 세 종류로 구분해 표기한다 — **[확인]** 공개 자료 · **[관측]** 우리가 직접 본 화면·산출물 ·
**[추정]** 앞의 둘에서 추론한 것. 추정을 확인처럼 쓰지 않는다.

---

## 1. 힉스필드의 프로세스

### 1-1. 입력 (상품)
- **[확인]** 상품 **URL 붙여넣기 또는 이미지 업로드** → 시스템이 **상품 정보를 자동 파싱**한다.
- **[관측]** `ADD YOUR PRODUCT` 모달: URL 입력칸 + `Create manually`. 등록된 상품이 카드 목록으로 남고
  **여러 생성에 재사용**된다("use your product across generations").
- **[관측]** 상품 카드를 열면 `Product name` / `Description`이 **이미 채워져 있고 수정·저장**할 수 있다.

### 1-2. 씬 구성 (두 블록)
- **[확인]** 영상 포맷의 씬은 **Hook + Setting** 두 building block으로 조립된다.
  - Hook = 주의를 끄는 장치(예: 물체가 프레임 안으로 날아 들어옴)
  - Setting = 장소와 분위기(예: 아침 햇살이 드는 주방)
- ⚠️ 우리 `ad_setup_items`(훅 20 · 장소 15)가 **바로 이 개념**이다. 시드 주석에 출처가 적혀 있다.

### 1-3. 레퍼런스 다중 입력
- **[확인]** 한 번의 생성에 **동시에** 넣는다: 제품 이미지 · **화자 얼굴** · **보이스 클립** · **카메라 스타일 레퍼런스**.
  텍스트만으로 근사하지 않고 입력을 모두 반영한다고 명시.

### 1-4. 포맷
- **[확인]** 6종: 제품샷 · UGC 영상 · 광고 · 마켓플레이스 이미지 · 포스터 · **모션그래픽**.
- **[관측]** 생성 바의 `2D product motion`이 그중 모션그래픽에 해당.

### 1-5. 계획 → 생성
- **[확인]** 자체 **reasoning engine**이 생성 **전에** 내러티브 구조·카메라 논리·시각 일관성을 계획하고,
  자체 모델(Soul·DOP)과 외부 모델(Seedance·Kling·Veo·Sora·MiniMax)을 오케스트레이션한다.
- **[확인]** 아바타를 씬에 배치하고 **제품과 상호작용**시킨다. 네이티브 오디오 + **립싱크**까지 한 번에.
- **[관측]** 모델 목록에서 `Marketing Studio Video`만 자기 브랜드 아이콘이고 스펙이 **720p–2K · 5–30초** —
  단일 벤더와 안 맞는 범위다. **[추정]** 설정에 따라 뒤에서 다른 모델로 **라우팅**한다.

### 1-6. 산출물
- **[관측]** 받은 파일: 2560×1440 · 24fps · 10.125초 · AAC 오디오 포함.
- **[관측]** 장면 전환 점수 최대 0.23(하드컷 기준 0.3) → **그 파일 안에는 컷이 없다.**
  체리 하나 → 방사형 → 꽃 → 단일 네일로 **연속 모핑**.
- **[관측]** 사용자 증언: 생성하면 **여러 씬이 만들어지는 과정과 결과**를 보여준다.
- **[추정]** 따라서 **씬 단위로 각각 생성**하고(각 씬은 컷 없는 연속 클립), 화면에서 씬들을 나열해 보여준다.
  받은 파일은 그중 한 씬이다.

### 1-7. 사용자가 하는 일 (중요)
- **[관측]** 프롬프트 한 줄 + 상품 선택 + (스타일·비율·길이·수량) → `GENERATE`.
  **훅·장소를 고르는 단계가 화면에 없다.** 즉 Hook/Setting은 내부에서 **자동 선택**된다.

## 3. 모방 계획 (단계별)

원칙 — **고르는 단계를 늘리지 않는다.** 힉스필드의 핵심은 기능이 많은 게 아니라
"프롬프트 + 상품"만 받고 **나머지를 자동으로 정하는 것**이다. 새 기능은 전부 자동 기본값을 갖는다.

### Phase 1 — 지금 것의 품질 확인 (선행, 필수)
1. Ad Studio ④로 실제 영상 생성 → 힉스필드 산출물과 **나란히 비교**
2. 어긋난 축을 기록: 제품 동일성 / 모션 자연스러움 / 화질 / 길이 / 오디오
3. **이 결과가 Phase 2의 우선순위를 정한다.** 이걸 건너뛰면 안 아픈 곳을 고치게 된다.

### Phase 2 — 격차 메우기 (Phase 1 결과에 따라 취사)
| 항목 | 무엇 | 크기 |
|---|---|---|
| a. 씬 나열 UI | 생성된 씬을 카드로 보여주고 개별 재생성 | 중 |
| b. N개 변형 | 같은 입력으로 2~4개 동시 생성 후 고르기 | 중 |
| c. 네이티브 오디오 | `ELEVENLABS_API_KEY` 설정 + 음악·나레이션 켜기 | 소(설정) |
| d. 카메라 레퍼런스 | 참고 영상/이미지를 넣으면 그 룩을 `[TECHNICAL]`로 번역 | 중 |
| e. 립싱크 | 외부 API(HeyGen·D-ID) 필요 | 대 |

### Phase 3 — 이미지 포맷 통합
제품샷·포스터·마켓 이미지는 **이미 78종 레시피가 있다**. Ad Studio 상품을 그 입력으로 넘기면
힉스필드의 6포맷과 같은 폭이 된다. 새 모델도, 새 엔진도 필요 없다.

### 하지 않을 것
- **자체 영상 모델 학습**(Soul·DOP 대응) — 학습 비용이 현 단계에 맞지 않는다.
- **Cinema Studio식 카메라 축 노출** — 저쪽도 Marketing Studio와 **별개 메뉴**다.
  고르는 단계를 늘리는 방향이라 지금 목표와 반대다. 필요해지면 그때 분리해 붙인다.

## 4. 알아둘 것

- **컷아웃(누끼) 한계** — 참고 영상의 "동일 제품 12개 복제"는 지금 프롬프트로 *지시*할 뿐 **보장되지 않는다**.
  Phase 1에서 이 축이 크게 어긋나면 배경제거 + 좌표 배치 렌더러를 별도 검토한다(신규 개발 규모 큼).
- **Hook/Setting은 이미 자동 선택**된다 — 사용자가 안 고르면 라이브러리를 모델에 넘겨 고르게 한다
  (`ad-studio.service`의 `auto`). 힉스필드와 같은 동작이다.
- 스타일이 `camera:false`(모션그래픽)면 훅·장소·아바타를 **뺀다**. 화자가 없는 영상에 대사 패턴이
  섞이면 결과가 깨진다(#271 실측).
