## 1. 30초 요약

1. **진짜 병목은 기술이 아니라 두 "프레이밍"이다. [확정]** ①크레딧 "충전"(특히 일회성 팩) → 포인트·사이버머니 위험업종(포트원 공식 우회책="월 구독 서비스이용료") ②"얼굴 셀카→합성" → 국제 브랜드(Visa/MC) 딥페이크 오인. 이 둘을 약관·카피로 먼저 정리하지 않으면 어떤 PG로도 반려.
2. **국내 KRW 먼저. [확정]** 해외(Eximbay+Visa/MC 직접)는 딥페이크·성인물 심사가 더 강함. 국내에서 약관·모더레이션 방어선을 먼저 검증하고 해외에 재사용. 단 Eximbay는 이미 "심사 막바지"라 별도 조정 필요.
3. **문서는 "심사표준 수준"이나 통과가능(passReady) 상태는 아님. [확정]** 체크리스트 판정 = `passReady=false`. 남은 실게이팅 = 실가격 라이브·빌링키 결제창·라이브 재배포 + 문서-실서비스 괴리 3건 해소.
4. **"결제창까지만 라이브면 심사 착수 가능"은 [가정].** 근거가 토스 커뮤니티 기준인데 제출 PG는 KCP/KPN → A0에서 직접 확인. 확인 전 병렬화(A5∥심사)는 "잠정".
5. **미검증 규제 단정 2건은 재검증 후 반영. [수정]** "KCP 2년 사업력 벽"·"전자상거래법 시행령 제20조의2(무료→유료 14일 전 동의)"는 참조 문서 grep 0건 → 1차 출처 재검증 전까지 의사결정을 몰지 않음(A0 과제).

## 3. 통과 전략 — 2관문

### 관문 ① 업종/BM 프레이밍 + 선지급식 실체 요건
- **[확정]** "크레딧 충전" → "월 구독 서비스 이용료 + 이용 한도(크레딧, 환금성 없음)"로 통일. 일회성 팩 → "추가 이용권/이용료"로 재표기.
- **환금성 없음 명문화** + 포인트 유효기간 설정(완화 요소).
- **🆕 결제대금예치/구매안전서비스 검토**: 팩이 "선불 충전"으로 분류되면 에스크로·소비자피해보상보험 의무 트리거 가능. 디지털콘텐츠 즉시제공은 대개 예외 → A0에서 PG에 서면 확인.
- **가격 정합 ↔ [제약] 충돌**: 표시가↔엔진가 30배·KRW 미연동 해소가 전자상거래법 제13조 실판매가의 전제인데, costMeter 실원가 확정 전 가격확정 금지(하드 제약)라 현 KRW=placeholder×환율=여전히 placeholder → **결정#0으로 승격**.

### 관문 ② AI 콘텐츠 정책·모더레이션 (브랜드 방어) [확정]
- **독립 AUP 페이지 신설**(현재 금지정책이 약관 제7조에 매몰 → 발견성 취약). 푸터·생성화면에서 직접 접근. ※약관 제7조엔 이미 성인물·비동의·딥페이크·퍼블리시티권 금지 존재 → 신설이 아니라 **표면화 + "연예인/실존 유명인 초상 무단 사용" 명시 보강**.
- **최소 모더레이션 파이프라인**(해외 붙이기 전 필수): 얼굴 업로드 동의 체크+기록 / 유명인·미성년 차단 / 신고→즉시삭제 / 생성물 AI 표기.
- **마케팅 카피**: "무엇이든 생성" 지양 → "제품/브랜드 콘텐츠"로 한정(커머스 포지셔닝 유지).
