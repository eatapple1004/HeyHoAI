# 음성 자막(Voice Subtitle) 재설계 — A+ (청크 자동분할) · 2026-07-10

## 0. 목표 (유저 결정)
- **대본 기본 자막 = 음성 자막**: 화면 자막이 "말하는 것(spoken)"을 그대로 보여준다.
- **독립 자막 = `+Add caption`(자유 자막)으로만** 추가. AI가 별도 헤드라인 자막을 자동 생성하지 않는다.
- **음성/자막 단일 소스 = 씬별 `spoken`**. 통 narration 편집기는 접는다(= 씬별 spoken 문장을 이어붙인 것이 전체 나레이션).
- **타이밍 = A+**: 씬의 spoken을 2~4단어 청크로 쪼개 씬 구간에 비례 분배(틱톡식). 실제 타임스탬프는 아님(추후 B로 업그레이드 가능, 청크 인프라 재사용).

## 1. 절대 불변식 (깨면 안 됨)
**글씨체·위치·크기·색 변경이 편집 프리뷰에 서버 왕복 없이 즉시 반영되는 시스템을 절대 건드리지 않는다.**
- 그 경로 = `u.subtitleStyle` → `ugcSyncCapAt`(studio:3504) → `ugcStyleCapOv`(studio:3532) → 오버레이 `.ugc-cap-ov` CSS.
- **A+는 자막의 텍스트/타이밍만 바꾸고, 스타일 적용 함수(`ugcStyleCapOv`)와 스타일 데이터(`subtitleStyle`)는 1도 안 건드린다.**
- 청킹은 "현재 ms에 어떤 텍스트를 보여줄지"만 정한다 → `ugcStyleCapOv`는 그 텍스트에 기존과 동일하게 스타일을 입힌다. 즉시반영 그대로.

## 2. 청킹 = 순수 결정론 함수 (프리뷰 == 번인 보장)
프리뷰 오버레이(클라)와 최종 번인(서버)이 **반드시 동일한 청크**를 내야 한다 → 양쪽에 같은 알고리즘 구현.

```
chunkCaption(text, startMs, durMs) -> [{ text, startMs, durMs }, ...]
  1. text를 공백으로 단어 분할.
  2. 그리디로 청크 구성: 한 청크 = 단어를 이어붙이되 (글자수 ≤ MAX_CHARS(한글 기준 ~14) AND 단어수 ≤ MAX_WORDS(4)) 유지.
  3. 각 청크 durMs = 청크 글자수 / 전체 글자수 × durMs (비례 분배), 최소 MIN_CHUNK_MS(600) 보장.
  4. startMs 누적. 마지막 청크 끝 = startMs+durMs로 클램프.
```
- 입력 같으면 출력 같음(랜덤·시간 의존 없음) → 클라/서버 결과 100% 일치.
- 빈 text → 빈 배열(자막 없음).
- 위치: 클라 = studio.html `ugcChunkCaption`, 서버 = `src/ugc/assembler/captionChunk.js`(신규, 동일 로직). 회귀테스트로 양쪽 동일성 검증.

## 3. 데이터 모델 (형태 불변, 소스만 전환)
`u.captionSpec.timings[]` 구조 **그대로**:
- **씬 자막**: `{ sceneN, startMs, durMs }` — 텍스트는 씬에서 파생. **파생 소스: `onScreenText` → `spoken`**.
- **자유 자막(독립)**: `{ id, text, startMs, durMs }` — 자체 텍스트. **변경 없음**(이미 `+Add caption`).
- **씬 자막은 저장상 여전히 "씬당 1개"**(=문장 단위). 청킹은 저장이 아니라 **표시/번인 시점의 순수 변환**. → 편집은 문장 단위로 단순 유지, 타임라인도 씬당 1블록.

## 4. 컴포넌트별 변경 (file:line)

### 4-1. 자막 텍스트 소스 onScreenText → spoken
- `public/studio.html:3624` `ugcTlCapText` → `s.spoken`(편집분 우선 `edits[n].spoken`) 반환.
- `src/ugc/renderPlan.js:39` `const text=(scene.onScreenText||'')` → `(scene.spoken||'')`.
- `ugcCapTextOf`(studio:3626)는 `ugcTlCapText` 경유라 자동 반영. 자유 자막은 t.text 그대로.

### 4-2. 표시(오버레이) 청킹 — `ugcSyncCapAt`(studio:3504)
- 현재: `matches`(현재 ms에 걸린 timing) → `ugcCapTextOf`로 통 텍스트.
- 변경: **씬 자막 매치**면 그 씬의 spoken을 `ugcChunkCaption(spoken, sceneStart, sceneDur)`로 쪼개 **현재 ms에 걸린 청크 텍스트**만 사용. **자유 자막은 청킹 안 함**(짧은 사용자 텍스트, 그대로).
- `data-sig`에 청크 텍스트가 들어가므로, 청크 바뀔 때만 DOM 교체(=의도된 카라오케 전환, 불필요 리빌드 없음).
- **`ugcStyleCapOv` 호출부·스타일 로직 그대로.** (불변식 1 준수)

### 4-3. 번인 청킹 — 어셈블러 `buildAss`(assembler:134/170)
- `assemble`에서 `plan.tracks.subtitle`의 **씬 자막 엔트리를 `captionChunk`로 확장**(1엔트리→N청크 Dialogue)한 뒤 `buildAss`. 자유 자막은 그대로 1엔트리.
- `subtitleAnim`(pop 등)·`posTag`·스타일 그대로 → 청크마다 등장 애니메이션 적용(틱톡식 팟팟).
- reRender 경로(`captionTimings` 클라→서버 통째 교체): 클라가 보내는 씬 엔트리도 서버에서 동일 `captionChunk` 확장. **또는** 클라가 청크를 미리 확장해 보냄. → **서버 확장으로 통일**(단일 알고리즘, 페이로드 작음). 단 클라 미리보기와 동일성은 §2 함수 일치로 보장.

### 4-4. 음성(spoken) 소스 단일화
- 음성 텍스트: `voSegments`(assembler:250, `spoken||onScreenText`) → `spoken`만. `ugcVideo.service` VO 키(41)·narrText(502)·getJob narration(983)도 `spoken` 기준으로 정리.
- **통 narration 편집기 접기**: 씬 스트립의 `📝 Narration` 행(studio:2943-2947) 제거. `narration` 필드는 백엔드 하위호환으로 남기되(옛 잡), 신규 = 씬별 spoken 이어붙임이 곧 나레이션.

### 4-5. 씬 카드 = 단일 텍스트 필드(spoken=음성=자막)
- 현재 씬 카드 💬(studio:2903, `onScreenText`, `ugcSceneEditCap`) 하나만 노출.
- 변경: 💬 필드가 **`spoken`을 편집**(라벨 "What's said & shown"류). `ugcSceneEditCap` → `spoken` 커밋(또는 `ugcSceneEditVoice`로 통합). onScreenText 편집 폐지.
- 편집 시 spoken 바뀜 → 자막(청크) + 음성 둘 다 갱신. (음성 재합성은 기존 캐싱 로직: 텍스트 바뀐 씬만 VO 재생성, 자막만 재조립은 무과금.)

### 4-6. 온-비디오 인라인 자막 편집(`ugcCapCommit` 등)
- 오버레이의 씬 자막은 이제 **청크(문장 일부)** 표시 → 청크를 그 자리서 편집하면 문장 매핑이 모호.
- 결정: **씬 자막 라인 클릭 편집 시 그 씬의 spoken 문장 전체를 편집**(청크가 아니라 문장 단위로 열기) → 커밋은 `spoken`. 자유 자막은 지금처럼 자기 텍스트 인라인 편집.
- 대안(더 단순): 온-비디오 편집은 자유 자막만, 씬 자막은 씬 카드/타임라인에서만 편집. → 1차는 이 단순안 채택 가능(추후 문장 인라인 편집 추가).

### 4-7. builder(생성) 변경 — `ugcScript.builder.js`
- voiceover 모드 지시 교체:
  - 현재: `onScreenText`=짧은 훅(READ), `spoken`=긴 문장(SAID), "never copy verbatim".
  - 신규: **`spoken` = 그 씬에서 말하는(=화면에 자막으로 뜨는) 자연스러운 한 문장.** 자막이자 음성이므로 **간결·구어체·씬당 1문장(청크 2~3개 분량, ~자막친화 길이)**. `onScreenText`는 생성 안 함(빈값). 독립 헤드라인 자막 자동 생성 금지.
  - `hook`/`cta`/`caption`/`hashtags`는 포스트용(off-screen) 그대로.
- 스키마(`ugcScript.service.js` SCRIPT_SCHEMA): `onScreenText`는 남기되 빈값 허용(하위호환), `spoken` 필수(voiceover).
- no-voiceover 모드: spoken/자막 모두 빈값(무음 비주얼) 그대로.

### 4-8. 독립 자막 위치(음성자막과 겹침 방지)
- 음성 자막(씬) = 기본 하단(preset bottom).
- 자유 자막(`+Add`) = 생성 시 기본 위치를 상단(또는 중앙)으로 시드해 하단 음성자막과 겹치지 않게. 사용자가 드래그로 자유 이동(기존 posX/posY 그대로).

## 5. 하위호환 / 마이그레이션
- **옛 잡**(spoken 비고 onScreenText만 있음): 표시/번인에서 `spoken||onScreenText` 폴백 유지 → 옛 영상 자막 안 사라짐.
- **옛 잡 narration 통짜**: 그대로 음성으로 재생(자막은 씬 spoken 기준, 없으면 폴백).
- 신규 생성부터 spoken 단일소스.

## 6. 검증 계획 (로컬, Kling 금지)
- **청킹 함수 동일성**: 클라 `ugcChunkCaption` vs 서버 `captionChunk` — 동일 입력 다수 케이스 출력 바이트 일치(한글/영문/짧은문장/긴문장/공백).
- **불변식 1(즉시 스타일)**: subtitleStyle 변경(font/pos/size/color) → `ugcStyleCapOv` 경로 무변경 확인(코드 diff에 스타일 함수 미포함), 오버레이 격리 렌더로 스타일 즉시 반영 재확인.
- **오버레이 청킹**: 시각 진행에 따라 씬 자막이 청크로 순차 전환·자유 자막은 통짜 표시(격리 하네스, ugcSyncCapAt 구동).
- **번인 근사**: assembler가 씬 자막을 청크 Dialogue로 확장(로컬 ffmpeg ASS 사이드카/번인, Kling 없이 정지이미지 dryRun).
- **회귀**: 자유 자막(+Add) 추가·드래그·삭제·타이밍 트림 기존대로. 옛 잡 폴백.

## 7. 구현 순서(제안)
1. `captionChunk` 공유 함수(서버) + `ugcChunkCaption`(클라) + 동일성 테스트.
2. 텍스트 소스 onScreenText→spoken(§4-1) + 오버레이 청킹(§4-2) + 번인 청킹(§4-3).
3. 씬 카드 단일필드(§4-5) + narration 행 제거(§4-4) + builder(§4-7).
4. 자유 자막 기본 위치(§4-8) + 온-비디오 편집 정책(§4-6, 단순안).
5. 하위호환 폴백(§5) + 검증(§6).
