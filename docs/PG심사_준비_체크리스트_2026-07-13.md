## 참고 (검증 조사 결과)
- **국외이전(활성)**: Anthropic(미국)·Google Gemini(미국, 얼굴)·Kling=Kuaishou(중국, 얼굴)·OpenAI(미국)·ElevenLabs(미국). 폴백/도먼트: Replicate·fal.ai·Runway·MiniMax(중국). → 방침은 활성 위주 기재, 얼굴이 미국·중국 이전됨을 명시.
- **PG 코드 현황**: Eximbay·LemonSqueezy만 코드 존재(둘 다 일회성, 키 미설정=미가동). **포트원+KCP는 코드 미구현(도입 예정)**. 정기결제(빌링키·스케줄러·상태머신)는 그린필드 → 개발자 작업.
- **인프라**: DB=AWS RDS(서울). 미디어=R2 설계됐으나 키 미설정 → 현재 로컬 tmp 저장(방침 '보관 위치'는 실배포 상태와 일치시킬 것).
