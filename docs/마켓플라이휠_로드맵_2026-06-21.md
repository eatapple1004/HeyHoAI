# 마켓 플라이휠 로드맵 — P1 완성 · P2 · P3 (2026-06-21)

> 전략 프레임(Leonardo 대비 우위) 위에서 "발견→전환→수익화" 플라이휠을 구축. 이 세션 = **P1 완성**.
> 다음 세션은 이 문서 + `docs/Custom_풀컨트롤_설계_2026-06-21.md`(기능 상세)를 먼저 읽을 것.

## 전략 프레임 (불변 — 의사결정 기준)
- **수직(마케팅 콘텐츠) + 결과중심 + 인물/제품 일관성(해자)** vs Leonardo의 수평 범용 툴.
- **유료 템플릿 = 크리에이터 경제**(로열티 70%) → Leonardo의 공짜 공유가 못 만드는 *다듬어진 공급* 유도.
- **🔑 유료 템플릿은 프롬프트 블랙박스**(결과만 노출, 레시피 비공개) — "프롬프트 공짜인데 왜 사?"의 해답.
- **공개 결과 피드 = 수요 엔진**, 유료 템플릿 = 수익화 하단. 피드는 마켓으로 흘러야(attribution + "내 subject로 만들기" CTA).
- 판매(유료)는 **후순위 점화** — 무료 Feed로 공급·수요 시드 먼저.

## ✅ P1 완성 (이 세션, upstream/main 푸시됨)
**발견↔전환 루프 + 자동공개.**
- **결과물 자동 공개**: 스튜디오 **🌐 Public 토글**(기본 ON). OFF=비공개. `generation_results.visibility`(기본 private·소급공개 방지). 영상은 아직 private.
- **Explore 피드**(`/explore`, 레일 신규): 모두의 공개 결과 마소너리 + 작성자 + **"Use [템플릿]" CTA** + 신고. `GET /api/generate/community`.
- **attribution**: 결과에 출처 템플릿 기록(`template_id/source/name`) → Explore 카드 "이 템플릿으로 만들기".
- **템플릿 상세 페이지**(`/template?id=`): 예시 갤러리·소셜증명·가격(Free/◈N)·**Use CTA**·**유료=블랙박스**(prompt null). `GET /api/marketplace/templates/:id`.
- **🔑 결과→템플릿(미리보기 캡처)**: Save as template 모달이 **방금 만든 결과 이미지를 `preview_media`로 자동 첨부** → Explore·상세가 시각적으로 살아남.
- **모더레이션**: 결과·템플릿 신고 3명 누적 → 자동 테이크다운(`result_reports`).
- (이전 세션 연속) 슬롯 이미지 입력(Start/End frame·Image Reference·Select Media)·비디오 풀 컨트롤·툴별 동적 폼.

### ⚠️ 배포 필수
`git pull → npm run migrate(필수: visibility·attribution·result_reports) → pm2 restart`. migrate 안 하면 **생성 결과 저장 실패**(컬럼 없음). theme.css 무변경 / rail.js는 `?v=2`로 캐시 갱신.

## ✅ P2 완성 (이 세션, 로컬 검증 — 푸시/배포 대기)
> 결정: **카탈로그=Explore 탭 통합(Discover 허브)** · **Saved=백엔드 북마크 테이블**(사용자 확정 2026-06-21). `/templates` 클린URL은 개발자 레거시 templates.html과 충돌 → Explore 통합으로 회피.
1. ✅ **Library 탭 재편**(`gallery.html`): My creations 항목별 **🌐/🔒 공개·비공개 토글 + 재공개**(`PATCH /api/generate/results/:idx/visibility`, taken_down 가드). "Feed" 탭 → **Saved**(북마크) 탭으로 교체(커뮤니티 발견은 Explore로 이관 = 중복 제거).
2. ✅ **Templates 카탈로그 = Explore Discover 허브**(`explore.html`): `[Creations | Templates]` 2탭. Templates 탭 = 카테고리 칩(All/Influencer/Shopping/UGC/Custom)·검색·가격(Free/◈N)·**★ 북마크 토글**. 딥링크 `/explore?tab=templates`.
3. ✅ **Creator 공개 프로필**(`/creator?handle=` = 단일세그먼트 클린URL, index.js 무터치): 스토어프론트(아바타·@핸들·템플릿수·♥) + 공개 템플릿 그리드 + 쇼케이스. `GET /api/marketplace/creators/:handle`(prompt 비노출=블랙박스). Explore 피드·카탈로그의 핸들이 프로필로 링크.
4. ✅ **영상 결과 자동공개 배선**: `videoJob.submit`/`finalizeSucceeded`가 visibility·attribution 운반→결과 기록. `/video/async`+`studio.html generateReel`이 privateMode·templateId/source/name 전송(이미지 경로와 동일 정책=기본 공개). ⚠️ Kling=0이라 영상 실생성 E2E는 키 확보 후.
- **북마크 백엔드**(신규): `template_bookmarks` 테이블 + `POST/DELETE /api/marketplace/templates/:id/bookmark` + `GET /api/marketplace/bookmarks`. 목록 응답에 `bookmarked` 플래그.

### ⚠️ P2 배포 필수 (안 하면 북마크·영상 attribution 깨짐)
`git pull → npm run migrate(필수: **template_bookmarks** 테이블 + **video_jobs**의 visibility/template_id/template_source/template_name 컬럼) → pm2 restart`. theme.css 무변경 → `?v=` 불필요. **로컬 검증 = 정적 UI(8098 throwaway)·라우트 마운트(401)·node 문법**까지(P1과 동일). 실 DB E2E·영상은 배포+migrate(+Kling 키) 후.

## ✅ P3 빌드 완성 (이 세션, 로컬 검증 — 푸시 대기 · **점화는 미실행**)
> 유료 경제 표면을 **전부 flag-gated로 구축**. 백엔드(charge·로열티 70%·earnings)는 이미 완비 → P3는 관리/UI 레이어. **`/creator` 충돌**(P2에서 공개 프로필로 사용) → 대시보드는 기존 **`earnings.html` 확장**으로 해소.
1. ✅ **가격 설정 UI**(`studio.html` Save 모달): ◈ price 입력(**공개+`featureOn('marketplace')`일 때만 노출**, `data-flag="marketplace"`). `priceCredits` 전송. 서버 0~100 클램프·크리에이터 게이트.
2. ✅ **PATCH `/api/marketplace/templates/:id`**(신규): 소유자가 name·price·visibility·category 편집. 공개 전환 크리에이터 게이트.
3. ✅ **Creator 대시보드 = `earnings.html` 확장**: 템플릿별 **Edit 모달**(이름·공개·가격)·Delete + Live/Private 배지. earnings 백엔드에 `visibility` 추가. Library "My templates"에 "Manage pricing & earnings →" 링크(flags.js가 prod 자동 숨김).
4. ✅ **Discover 카탈로그 Free/Paid 필터**(`explore.html`, `data-flag="marketplace"`): All/Free/Paid 칩.
- **유료=블랙박스**: 상세(`/template?id=`)에서 이미 prompt null 처리(P1). 카탈로그/프로필은 prompt 미노출.

### 🔴 P3 점화(go-live) 레버 — **사용자 결정, 미실행**
- **점화 = `public/js/flags.js`에서 `marketplace`·`earnings`를 `launch:true`로** (+배포). 그 전까지 prod는 가격필드·Paid필터·earnings페이지·"Manage" 링크 전부 자동 숨김(로컬은 "main hidden" 배지로 노출). **점화 조건=양질 공급 임계**(공식 시드 + 크리에이터 모집) — 로드맵상 아직.
- **돈 라우트 백엔드 게이트 권장**: flags는 프론트 전용. 점화 전 paid `/use` 과금에 env 게이트(예 `MARKETPLACE_PAID`) 추가 = 방어. (현재는 가격설정 UI가 flag로 막혀 prod에 유료 템플릿이 안 생기므로 사실상 안전.)
- **페이아웃**: 현금 이체는 **미구축**(earnings='Coming soon' 정보성). 실제 정산은 별도(Stripe Connect 등) — 안전상 세션이 실행/구축 안 함.
