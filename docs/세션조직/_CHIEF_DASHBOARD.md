## 3) 교차도메인 결정 (Chief 전속 — 단일 도메인이 못 끝냄)

### A. 가격 = 엔진 실원가 + 백엔드 과금 + 그로스 전략

**현 상태 판정**: 가격은 **의도된 placeholder 유지가 정답**(엔진 COGS 미수집). 단일소스 설계 완료(`pricing.js`→`/api/pricing`, 전 페이지 `data-dp` 자동동기화, 하드코딩 누수 0). **릴리스 비차단**(`blocking:false`).

**그러나 Chief가 닫아야 할 가격 결정 2건:**

- **A-1. COGS 수집 발주(가격 확정 입력)** — `costMeter.js`의 `PROVIDER_COSTS`는 프로바이더 공식단가 기반 *추정*. 실청구(Nano Banana/FLUX/Runway/Kling) 검증 + `generate`마다 `meterGeneration→generation_costs` 로깅 필요. **현재 호출처 0**(엔진 §6 미연결)이 근본 병목. → **엔진+백엔드에 발주.** 그 전까지 `pricing.config.js estimated:true` 유지.
- **A-2. ⚠️ 카니발 불변식 위반 — Chief 시정 지시.** 불변식 "구독 단가 < 팩 단가"가 **대형팩에서 깨짐**:
  - Creator $19/250 = **$0.076/cr**, Pro $39/600 = **$0.065/cr**, Brand $79/1400 = $0.056/cr
  - 대형팩 $110/1750 = **$0.063/cr** → **Creator·Pro보다 싸다.** billing의 "구독이 항상 더 싸다" 카피와 모순(신뢰 이슈).
  - **결정**: 상대 단가 순서는 COGS와 무관한 *전략 레버*이므로 **지금 시정 가능.** 그로스에 발주 — (택1) 대형팩 단가를 Pro 위로 재정가 / Creator·Pro 크레딧 증량 / 팩 상한 하향. **불변식 = Brand < 모든 팩 < Pro·Creator 진입팩** 으로 재정렬. (절대가는 COGS 후, 상대순서는 즉시.)

### B. 게이팅 = 백엔드 강제 + 프론트 노출 — **🔴 CONFLICT (릴리스 차단)**

**판정**: 프론트 신호는 정상 구현, **백엔드 강제는 0%**. 서버가 모든 요청 무조건 승인 → 신호가 무의미.
- 프론트(정상): `recommendTier()`(신호기반)·`showUpsell()`(Pro→Brand 2단계)·`isCommercialMode()`. **정의 변경 불필요.**
- 백엔드(부재): users에 plan/credits/first_seen 없음, `POST /api/generate`에 크레딧 검증·차감 0, `requireEntitlement()` 미들웨어 없음, 워터마크 강제 클라이언트뿐.

**Chief 결정 — 신호 정의는 프론트로 확정, 백엔드는 그 신호에 권한만 매핑:**
1. **프론트 신호 = 현행 확정**(BACKEND_HANDOFF §4 스펙과 일치). Brand=`variants≥10`+상업다운로드, Pro=4K·brandKit·caption·반복·streak. → 백엔드는 *재정의 말고* 이 신호에 맞춰 강제.
2. **백엔드 발주(개발자 합류 시 §1~§4)**: users 확장 → `/api/auth/me`가 plan·credits·firstResultAt 반환 → `/api/generate` 사전 크레딧검증(부족=402) → 다운로드/게시 직전 entitlement 검증 → 무료 첫결과 후 워터마크 서버 강제.
3. **2단계 분리 문서화**(BACKEND_HANDOFF §4 갱신): Stage1 프론트=권유(모달), Stage2 백엔드=강제(402+인라인 페이월). 워커 참조용.
