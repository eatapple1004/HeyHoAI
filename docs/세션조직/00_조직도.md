## 운영 루틴 (Chief)
1. 주기적으로 각 도메인 `_STATUS_*.md` 취합 → `_CHIEF_DASHBOARD.md` 롤업.
   ```
   for f in docs/섹션명령서/_STATUS.md docs/세션조직/_STATUS_*.md; do echo "== $f =="; [ -f "$f" ] && tail -5 "$f" || echo "(없음)"; done
   ```
2. 블로커·교차의존(예: 그로스 가격확정 ← 엔진 COGS) 조정.
3. 7도메인 DoD 그린 → `main` 머지 승인(사용자 승인 후 push).
4. (옵션) 세션 간 실시간 조율: `mcp__ccd_session_mgmt__{list_sessions,send_message}`.
