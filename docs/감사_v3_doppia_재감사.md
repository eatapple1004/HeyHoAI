# Doppia Studio UI 재감사 (v3) — 플로우 최적화 + 수익화 극대화

작성: 2026-06-08 · 방법: 18개 렌즈(14 페르소나 + 4 수익화 전문가) 병렬 평가 → 발견 클러스터링(17테마) → 테마별 소스 대조 적대적 검증 → 종합 + 완전성 비평 (42 에이전트). 대상 = 우리 소유 Doppia 9페이지 + hh.js (mock UI, 백엔드 없음).

## 결론 (bottom line)
**아니다 — 구조는 정교하지만 페르소나별 플로우 최적화는 아직이고, 설계된 수익의 ~60–70%만 포착.**
- **플로우 5/10**, **수익화 구조 6/10**.
- 직전 감사의 핵심 진단("전환은 잘하나 덜 뽑는다")은 이번 작업으로 실제로 해소됨(티어-라우팅·Pro$39·UGC 리프라이싱·$5 소액·Team/화이트라벨·셀러/earnings·캡션·week set·value-rec 전부 구현).
- 그러나 **3대 구조적 누수 + 결제 순간 신뢰 훼손**으로 실현 포착이 설계에 못 미침.
- 영향: 인플루언서(원래 타깃)엔 좋고, **셀러·팀·공급측·비영어권으로 갈수록 급격히 악화**(비영어권 Yuki 2/2).

## 3대 구조적 수익 누수
1. **recommendTier()가 모드만 보고 라우팅** (studio.html:714–718). product/ugc면 무조건 **Brand $79**(소액 셀러 과잉요구→이탈), 인플루언서는 **Creator $19에 고정**(매일 캡션 쓰는 최고가치 유저에게 Pro $39를 안 보여줌). 직전 감사 #1 Top무브("1.7~2배 LTV")는 구현됐으나 **작업신호 아닌 모드**로만 분기 → 양방향 손실.
2. **교차페이지 크레딧/라이선스 모순.** Creator 200 vs 250, Brand 1,000 vs 1,400 (랜딩·billing 상태줄 = 옛 200/1,000, billing 카드·studio 실지급 = 250/1,400). Brand 카드가 Pro 상속기능(브랜드킷·캡션) 침묵 누락. 랜딩은 Creator가 Personal 라이선스임을 안 알림 → **landing→billing 경로에서 미끼상술처럼 읽힘**.
3. **$79 미만 상업권 매물 부재 + 랜딩에 Pro 없음.** 랜딩 가격표는 Free/Creator/Brand 3장뿐(Pro $39는 billing에만). 코드 어디에도 상업권을 $79 미만과 묶은 매물 없음 → WTP $20–40 솔로 셀러가 $19→$79 절벽.

## 결제·이탈 순간 신뢰 훼손 (전 페르소나 공통)
- **결제/확인 문구 ~100%가 한국어** (영어 UI 안에서): 페이월·티어피치·업셀·토스트·가입성공·약관. studio/billing/business/affiliate/gallery 전반. **현재 최대 미해결 누수** — 비한국어 구매자는 결정 순간 화면을 못 읽음. (hh.js가 "한국어 alert 정리"했다지만 alert→toast만 바꾸고 카피는 한국어로 남김.)
- **가짜 50% 긴급 배너**(상시 노출 = 허위 긴급) + **뒤집힌 cancel confirm()**(OK=pause로 유저를 가둠) — 진입과 이탈 양쪽 신뢰 파괴.
