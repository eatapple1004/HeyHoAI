# 결제경로 PPT 캡처 체크리스트 (토스페이먼츠 심사용)

토스페이먼츠 「홈페이지 결제경로 제작 가이드」 **충전업종용**·**정기결제용(빌링)** 2종을
Doppia 실제 화면에 매핑한 문서. 캡처 순서와 "어느 URL에서 무엇을 찍을지"를 고정한다.

- 근거 문서: 토스페이먼츠 결제경로 제작 가이드 (충전업종용 2023-12-29 / 빌링 2024-07-01)
- 대상 사이트: **https://doppia.ai** ← ⚠️ 심사는 **라이브(prod)** 를 본다. dev로 찍으면 안 된다
- 관련 작업: PR #224(한도·약관), #227·#228(빌링키)

---

## 0. 공통 규칙 (두 문서 동일 — 위반 시 반려)

| # | 규칙 | 확인 |
|---|------|------|
| 1 | **PPT 형식**으로 제작 (카드사별 양식 수정이 필요하므로 PDF·이미지 불가) | ⬜ |
| 2 | 모든 캡처에 **도메인 주소(URL)가 보이도록** — 주소창 포함 | ⬜ |
| 3 | **북마크바 숨김** (⌘⇧B) — 가이드가 "북마크바 없이"를 명시 | ⬜ |
| 4 | **PC 시계가 함께 보이게** 캡처 (빌링 가이드 필수. 카드사가 시간 흐름으로 조작 여부를 판단) | ⬜ |
| 5 | 테스트 계정으로 **로그인 과정까지** 캡처 | ⬜ |
| 6 | 테스트용 결제창으로 연동돼 있어도 심사 가능 | — |

> 💡 **캡처는 전체 화면**으로. 브라우저 창만 잘라내면 URL·시계가 빠진다.

### ③ 충전 관련 이용약관 캡처
- **URL**: `https://doppia.ai/terms` → **제10조 (크레딧)**
- 가이드가 요구하는 **필수 3항이 모두 이 조에 있다**:

| 가이드 요구 | 우리 약관 |
|---|---|
| 환불은 결제되었던 수단으로 | 제10조 ⑥ (원 결제수단 명시) |
| 회원간 양도 불가 | 제10조 ⑤ |
| 사용·취소/환불 기한 1년 이내 | 제10조 ⑥ (이용기간·환불가능기간 모두 1년) |

> 제10조 ⑦에 "1회 충전 10만원 미만" 도 있으니 같이 보이게 찍으면 ⑥ 단계 설명이 쉬워진다.

### ④ 취소 / 환불 규정 캡처
- **URL**: `https://doppia.ai/refund` → **제4조 (크레딧 팩 환불정책)**
- 미사용 전액 환불 / 부분 사용 시 산정식 / 환불가능기간 1년 / 원결제수단 환불이 한 화면에 들어간다.

### ⑤ 로그인 경로 캡처
- **URL**: `https://doppia.ai/login`
- 비회원 구매 없음 → 로그인 화면 필수. 회원가입 경로(`/signup`)도 같이 찍어두면 안전.

### ⑥ 상품 선택 / 구매 과정 캡처
- **URL**: `https://doppia.ai/billing`
- **가이드 핵심 제약 — 우리는 이미 충족**:
  - ✅ 임의 금액 입력 없음 (선택형 옵션만)
  - ✅ 최고가 **10만원 미만** — 국내(KRW)에서 `₩15,000` / `₩81,000` 2종만 노출 (PR #224)
- 찍을 것: 팩 목록 → 선택 → 결제 버튼까지의 흐름 **전부**

> ⚠️ **통화 토글을 KRW로** 두고 찍을 것. USD로 두면 10만원 초과 팩(₩329,000·₩579,000)이 보인다.

### ⑦ 카드 결제경로 캡처
- PortOne 결제창 → **신용·체크카드** 선택 → 카드사 선택 → 인증 화면
- **비씨 / 농협 2개 카드사는 필수** (가이드 명시). 각 카드사 인증 화면까지 캡처
- 결제 **완료** 화면까지는 불필요

> ❓ **확인 필요**: 현재 PortOne 채널에서 비씨·농협이 선택 가능한지. 채널 설정에 따라 노출 카드사가 다르다.

### ⑧ 결제 후 사용처 캡처
- **URL**: `https://doppia.ai/studio`
- 충전한 크레딧이 **실제로 쓰이는 화면**: 생성 시 크레딧 차감 표시, 잔액 감소
- 가능하면 `/billing`의 잔액 변화도 같이

## B. 빌링용 PPT (①~⑥) — 정기결제  ✅ 제작 대상

### ① 가맹점 정보 기재
충전용과 동일 (별도 파일이므로 표지 다시 작성).

### ② 하단 정보 캡처
충전용 ②와 동일. 단 빌링 가이드는 **유선전화번호**를 명시 — `070-8098-3546`(인터넷 유선)이라 충족.

### ③ 환불규정 캡처 (무형상품)
- **URL**: `https://doppia.ai/refund`
- 가이드 예시는 "정기결제 회원 일할 계산" 형태다. 우리 `/refund` **제5조(구독 플랜의 자동갱신·해지·중도해지 환불)** 가 이에 대응.

### ④ 로그인 / 회원가입 캡처
충전용 ⑤와 동일.

### ⑤ 상품 선택 / 구매 과정 캡처
- **URL**: `https://doppia.ai/billing` → 구독 플랜 섹션 → 플랜 선택 → 구독하기
- ⚠️ 구독 노출은 `SUBSCRIPTIONS_FOR_SALE=true` 일 때만. **prod에서 켜야 캡처할 수 있다.**

### ⑥ 카드 결제경로 캡처
- **URL**: `https://doppia.ai/billing` → 하단 **"Payment method · 결제수단"** 섹션 → **카드 등록**
- PortOne `requestIssueBillingKey` → **정기결제용 카드 입력창**(카드번호·유효기간 → 본인확인)
- 가이드가 요구하는 "정기결제용 카드 입력창까지" 가 정확히 이 화면

## 📌 결정 이력 — 빌링 제외 → **철회** (2026-08-13)

- 2026-08-12: 구독 판매를 중단했으므로 "빌링을 신청 범위에서 빼달라"고 회신하기로 했었다.
- **2026-08-13: 철회.** 빌링(정기결제)을 심사 범위에 **포함**한다.
  → 구독을 다시 팔고, 빌링용 PPT도 제작한다. 제출물은 **충전용 + 빌링용 2개**.

### 그래서 선행되어야 하는 것

| # | 항목 | 상태 |
|---|------|------|
| 1 | 구독 플랜 판매 노출 (`SUBSCRIPTIONS_FOR_SALE=true`, prod까지) | 화면 복원됨 — **prod에서 켜야 함** |
| 2 | 구독 개시 = 빌링키 발급 → 첫 청구 → `activatePlan` | ❌ 미구현 (`/api/subscription/upgrade`는 501) |
| 3 | 자동 재청구 스케줄러 (월) | ❌ 미구현 |
| 4 | 해지 / 카드 교체 UI | ❌ 미구현 |

②가 없으면 빌링 PPT ⑤(상품 구매 과정)에서 **결제가 실제로 진행되지 않는다.**

### 🚨 착수 전에 토스에 먼저 물어야 할 것

**"구독 플랜도 포인트충전으로 보아 1회 10만원 한도가 적용되는가?"**

적용된다면 판매 가능한 플랜은 Starter(₩31,000)·Standard(₩81,000) **둘뿐**이고
Pro(₩164,000)·Premium(₩329,000)·Enterprise(₩990,000~₩1,990,000)는 국내에서 팔 수 없다.
→ 플랜 구성을 다시 짜야 하므로, **개발 착수 전에 답을 받는 편이 싸다.**
