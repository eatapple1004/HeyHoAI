### 🔴 H 설계 이탈 (다음 세션 결정 사항)

**§3 규칙과 어긋난다. N개 동시 생성은 되지만 흐름이 설계와 다르다.**

| 설계(§3 규칙·배치) | 실제 구현 |
|---|---|
| Generate → 잡이 **오븐으로** 떨어지고 조리대 비워짐 | `ugcRenderVideo`(≈5152) `pending._bench=true` → **조리대에 남음** |
| "**렌더 중인 건 조리대에 안 올림**" | 렌더 중인 게 조리대를 점유 — **정면 모순** |
| 오븐으로 **자동 스크롤 1회** | **미구현** |
| 완성 시 조리대 비면 **자동 승격** | **죽은 코드(도달 불가)** ↓ |

**자동 승격이 죽은 이유(두 겹)**
1. `ugcBenchFree()`는 `!ugcScript`를 보는데 **`ugcScript`가 null로 되돌아가는 코드가 없다** — 대입은 `let ugcScript=null`(4842)과
   `ugcScript=data.script`(4939) 뿐. 첫 대본 이후 영원히 non-null → `ugcBenchFree()`는 항상 false.
2. 승격 조건 `if(!pending._bench && ugcBenchFree())`인데 `pending._bench`가 애초에 true라 `!pending._bench`도 false.

⚠️ 커밋 `1eaf6ff`의 "1개생성 자동승격 검증"은 **테스트에서 `ugcScript=null`을 손으로 넣은 것**이라 실사용에서 못 일어나는
상태를 통과시켰다. 검증 자체가 틀렸다. (사용자 눈에 보이는 버그는 아니다 — 1개면 영상이 조리대를 떠난 적이 없어
결과적으로 "지금과 동일한 경험"은 나온다. 대신 2개째를 만들려면 Edit → 새 대본을 거쳐야 한다.)

**결정 두 갈래**
- **(a) 설계대로 마저 간다** — `pending._bench=false`(오븐행) + Generate 후 조리대 비움 + 오븐 자동 스크롤 +
  **Generate 후 `ugcScript=null`로 리셋**(자동 승격이 살아나는 전제). 문서 의도 그대로, N개 쏘기가 1급.
  문서의 근거: "렌더 중인 건 조리대에 안 올림 — 잡이 processing이라 할 게 없고, 피드 카드가 이미 그 화면."
- **(b) 현재 변형을 채택** — 조리대에서 지켜보다 새 대본 쓸 때 내려감. 그러면 **G의 자동 승격·`ugcBenchFree()`는
  죽은 코드이므로 삭제**해야 한다(지금은 남아서 읽는 사람을 속인다).

→ 권장 **(a)**. (b)는 손댈 수 없는 렌더가 조리대를 점유해 설계가 반대한 상태 그대로다.

## 2. 검증된 사실 (다시 파지 말 것)

### 데이터 흐름 — 완성 ≠ 라이브러리
```
렌더 중    ugc_jobs status='processing', script=NULL, result_idx=NULL
  ↓ 완성   status='succeeded', result_url 있음, result_idx=NULL   ← draft. 어디에도 안 보임
  ↓ 저장   Save & finish 또는 이탈 시 sendBeacon → generation_results 행 생성 → result_idx 채움
           → 이제야 크리에이션 피드 · Library · home 에 뜸 (셋 다 /api/generate/results 단일 소스)
```
- **자동 커밋 스위퍼 없음**(`sweepStaleCommits`는 존재하지 않음 — `sweepStaleComposites`와 혼동 주의)
- 편집 후 반영: `if (row.result_idx)` 가드 → `UPDATE generation_results ... WHERE idx=result_idx`(3곳). **draft면 스킵**
- prod 실측: succeeded 89 → 저장됨 83 / draft 6(13h~180h 방치). generation_results 연결 = 정확히 83

## 3. 설계 (확정)

> **오븐엔 여러 개. 조리대엔 하나. 새 걸 올리면 이전 건 저장되어 내려간다.**

### 축 분리 — 설계의 심장
```js
isUgc  = "이건 Ad Video 배치다"     → 피드에서 배지·씬 스트립
_bench = "지금 조리대에 올라와 있다"  → 피드에서 제외, 워크벤치로
```
지금 `isUgc` 하나가 두 뜻을 겸해서(`if(b.isUgc)return` = 피드 제외 + 워크벤치행) N개가 불가능했다.

### 배치
| 상태 | 어디 |
|---|---|
| 입력·대본 검토 | 조리대 |
| **렌더 중 N개** | **오븐(피드)** — 로딩 카드가 곧 "생성보기"(큰 9:16 + 경과초 + 씬 카드) |
| 완성·미저장 | 오븐 `[저장][편집]` + 배지 카운트 |
| 저장됨 | 오븐 `[편집]` = Library = home |
| **편집 1개** | 조리대(씬 스트립·자막·오디오 **그대로 유지**) |

### 규칙
- **Generate 누르면**: 잡이 오븐으로 떨어지고 **조리대 비워짐** + **오븐으로 자동 스크롤 1회**("어디 갔지" 방지)
- **동시에 두 곳에 뜨지 않음**: 편집은 `_dirty`로 클라에만 쌓여 저장 전엔 DB와 다름 → 두 곳에 띄우면 **같은 영상의 두 버전**이 한 화면에 (정합성 문제)
- **완성 시**: **조리대가 완전히 비어있으면(대본 없음 + 편집 없음) 자동 승격**, 차 있으면 오븐 대기
  - 1개만 생성 = 자동으로 뜸 → **지금과 동일한 경험** (이 가드가 없으면 단일 케이스가 클릭+스크롤만큼 손해)
- **렌더 중인 건 조리대에 안 올림** — 잡이 processing이라 할 게 없고, 피드 카드가 이미 그 화면

## 5. 🔴 절차 (오늘 배운 것 — 반드시)

1. **매 단계 인라인 `<script>` 추출 후 `node --check`**
   오늘 `ugcRestoreActiveJobs`에서 `let pending`(API응답)과 `const pending`(배치)이 같은 스코프에 겹쳐
   `SyntaxError: Identifier 'pending' has already been declared` → **studio.html 인라인 블록 전체가 파싱 실패**해
   `bootFromUrl`·`STUDIO_BATCHES` 등 모든 함수가 사라졌다. **`node --check public/studio.html`은 HTML이라 통과한다.**
   더 위험했던 건 `rail.js`는 별 파일이라 **배지가 정상으로 보였다**는 것.
   ```bash
   python3 - <<'PY'
   import re,subprocess,tempfile,os
   s=open('public/studio.html').read(); bad=0
   for m in re.finditer(r'<script(?![^>]*\bsrc=)[^>]*>(.*?)</script>', s, re.S):
       c=m.group(1)
       if not c.strip(): continue
       with tempfile.NamedTemporaryFile('w',suffix='.js',delete=False) as f: f.write(c); p=f.name
       r=subprocess.run(['node','--check',p],capture_output=True,text=True); os.unlink(p)
       if r.returncode!=0: bad+=1; print("🔴 "+r.stderr.strip().split('\n')[3][:90])
   print("✅ OK" if not bad else f"오류 {bad}")
   PY
   ```
2. **매 단계 개발자 식별자 개수 대조** — `ugcToggleAdv`=3 · `.ugc-adv`=24 · `.ugc-sum`=12
   (오늘 `ugcToggleAdv(jobId,n)`= "✎ Edit scene" 토글을 무인자 함수로 덮어쓸 뻔했다. 개명으로 회피)
   ⚠️ **E 단계엔 이 방식이 안 통한다** — 같은 함수 안을 고치므로 개수로는 안 잡힘
3. **매 단계 브라우저 실검증** — 클래스 유무가 아니라 실제 동작
4. **커밋은 단계별로** — 뭉치면 되돌리기 불가
